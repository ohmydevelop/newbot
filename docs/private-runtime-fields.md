# 私密字段与任务授权

Issue 06 在 SQLite 配置模式下增加 Provider API Key、HTTP MCP Bearer / 自定义请求头，以及 stdio MCP 环境变量。连接器名称由用户填写，内部标识自动生成；外部服务要求的字段名称仍需准确填写。

## 保存与派发

普通设置保存和远程目录发现相互独立。全局默认模型只影响新会话。`GET /api/config?view=saved` 读取已保存配置；模型、技能、连接器目录通过独立接口按需发现。默认模型保存不重启运行时或恢复已有线程。

密值经 `/api/credentials/*` 二进制输入通道提交。普通配置只提供字段名称、修订及是否已保存；`private_field_sets` 保存经 AES-256-GCM 加密的值，并绑定网关端点或连接器的地址、程序及参数。解密钥保存在工作区外受保护文件中，需与 SQLite 一起备份。密钥不可通过配置接口回读。

Bridge 在 Codex 原生线程创建/恢复的最后边界注入请求头或环境变量。扩展快照、运行请求、日志和对话均不保存这些私密参数；全局保存只影响后续任务，不轮换共享进程环境。旧版托管 API Key 引用仍可读取，并在执行边界转换为目标线程的参数。

## 对话授权

在连接器或网关编辑器选择“在对话中授权”，会清除该对象已保存的字段值，保留所需字段定义。任务派发前 Bridge 根据所选网关及启用的连接器显示受信任输入卡；普通模型文本和 A2UI 表单不能发起这类请求。

- **仅本次任务**：绑定稳定请求 ID，结束或取消后释放，并清理原生线程连接。
- **当前会话**：绑定原生线程，仅在该会话后续轮次复用；撤销、归档或服务重启后失效。关闭浏览器不会撤销。
- **全局保存**：字段值加密持久化，服务重启后恢复；更换接收方后原授权不适用，需要重新输入。

新会话等待授权时尚未创建原生线程。授权通过后创建线程并绑定会话授权；不会尝试卸载/恢复尚未产生首轮记录的空线程。

聊天顶部“会话私密授权”可更新配置接收方的授权或撤销授权。更新供下一次任务使用，不自动重新执行认证失败的工具。撤销时也取消该会话尚未完成的授权请求，正在执行的任务会被中断。等待任务最多保留 30 分钟；服务重启后记为未执行，不能自动重放。

## 失败与恢复

正常提交、等待授权和发送结果未知分别显示。请求 ID 绑定原会话或草稿；正常提交超过确认时限、丢失响应或刷新后，以只读接口查询权威结果。核对到成功后解除等待，不重复派发；其他会话仍可使用。未登记的请求只有在用户主动放弃并由服务端建立拒绝记录后才解除。

全局设置及私密字段均有操作结果查询。已确认的数据库写入不会因为目录发现失败变为保存失败。凭证输入响应丢失时先查询状态，不能自动重复提交密值。

## 验证边界

固定 Codex 0.165.0 与隔离的模拟 HTTP/stdio 接收方已验证私密注入、一次/会话作用域、跨线程隔离、撤销、重启恢复和检查范围内的明文隔离。该验证不代表所有真实 Provider/MCP 服务兼容。此功能不提供通用 sudo 执行器、长期记忆或任意模型发起的私密请求。历史 native 配置兼容模式不宣称支持新的字段注入；以能力查询为准。
