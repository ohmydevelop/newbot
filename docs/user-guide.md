# 使用指南

适用：0.2.0 开发功能冻结候选版。已有测试分享仍使用原密码；当前入口见 [Cloudflare 分享说明](cloudflare-sharing.md)。正式部署与上线验收另见 [R1 计划](roadmap.md#r1-开发完成后的统一验收)。

## 登录与开始聊天

访问主站，输入实例密码。新实例的随机密码保存在服务器 `.data/initial-password`；该文件已存在时启动会沿用其中的密码（清空数据库不会更换密码），设置过 ADMIN_PASSWORD 时以环境变量为准。密码不会显示在普通配置页面。

点击“新聊天”，选择模型和思考强度，输入问题。Enter 发送，Shift + Enter 换行；输入法选字时不会发送。上传完成后才能发送，每条消息最多 8 个附件、每个最多 8 MiB。当前支持图片与有限 UTF-8 文本输入，其他文件不等于模型能直接理解。

可从“技能”明确选择已发现的技能。发送前服务端重新检查可用状态与内容，历史会保留原技能引用；技能说明是只读文件，不会因为查看而执行。浏览和启停见侧栏“技能”。条目点击查看完整说明；可管理的独立个人技能提供卸载，移出发现目录并保留服务端备份。项目、系统、管理员及插件技能显示来源限制。

## 历史与草稿

侧栏可搜索已保存的对话标题、重命名或归档。搜索只查标题，不是全文搜索。进入对话默认读取最近 30 轮，需要时点击“加载更早的消息”；加载失败可重试，原内容和阅读位置保留。

切换对话会保留当前页面内的文字、附件和技能选择。**这些聊天草稿只在内存中保存，刷新、退出或关闭页面后不会恢复。** A2UI 的普通表单草稿有独立的服务端保存流程，不能与聊天草稿混为一谈。

运行中的任务需要授权时，在对应对话中允许或拒绝。普通命令/文件审批按显示的范围生效，权限类请求明确标为“允许本轮权限”。归档不会删除原生历史；活跃或正在开始的任务必须先结束。

## 断线、停止与发送未确认

关闭页面或断网不会主动中断后台 Codex 任务。重新打开后读取权威历史；待审批请求在 Bridge 仍运行时可以继续呈现。Bridge/Codex 进程退出后，不保证正在执行的任务自动续跑。

“停止回答”只发出中断请求，界面等待真实状态。若结果未确认，先“读取停止状态”；仍在运行时可再次明确请求。系统不会自动反复中断。

若发送响应丢失，使用“检查发送状态”，不要重复输入相同任务碰运气。已确认提交的任务会显示对应对话；未确认时保留请求 ID。只有服务端尚未登记的发送，才能明确“放弃尚未登记的发送”；成功后迟到请求不会执行。该操作不能撤销已经运行的任务。

浏览器刷新前先复制未发送内容。状态读取、预览、重新显示内容和恢复连接都不会自动重新发送模型任务。

## 文件、App 与动态表单

Agent 生成并登记的文件以卡片显示，可查看历史版本、预览或下载。也可从“添加工作区文件”选择允许的文件，不提供任意服务器路径读取。后续文件修改不会悄悄替换已保存版本。

自包含 HTML 在隔离窗口运行，外部网络与任意工具权限关闭。PDF 是只读分页/缩放预览。文件存储设置可清理未引用数据，不会自动删除历史引用来腾出空间。取消上传不能撤回已收到的文件，未发送附件按既有 24 小时策略清理。

MCP App 需要独立应用域。App 的“权限与能力”说明实际开放内容；反向工具调用逐次授权，仅限当前 Server/UI 资源对应工具。不支持的请求会明确失败，重新打开不会恢复旧授权。

A2UI 表单由受限原生组件渲染，只填写普通信息。保存状态会显示在表单内，冲突时先读取或重新加载。服务重启后的旧表单只读，不能自动恢复提交权限。MCP 普通信息表单同样不能接收密码或 API Key。

内置测试 MCP：ENABLE_TEST_MCP 启用后，可让 Agent 调用 show_metrics，显示模拟 CPU、内存和磁盘图表；它不读取真实系统指标。见 [测试示例](../examples/test-mcp/README.md)。

## 配置与私密输入

模型网关在设置中管理，填写名称、连接地址和 API Key 即可，内部标识和凭证引用由工作台自动管理。编辑时密钥留空保留，清除需单独确认。工具连接与插件合并管理，点击条目查看详情，通过更多菜单启停、编辑或卸载；插件附带的连接在插件详情中管理。有版本冲突或保存结果未知时，先读取实际状态，不盲目再次保存。切换网关和重载配置需要运行时空闲。

基础连接诊断不等于完整 Agent 兼容。第三方 Provider 可能不支持工具、推理参数或上下文恢复，只有实际验证过的模型可作相应承诺。

网关编辑器的 API Key 使用私密提交，默认本机加密保存，也可选择仅本次运行。HTTPS MCP 的密钥使用其详情中的私密输入入口，选择所需保存方式。保存后不可回读，可更新或清除；内存凭证在服务重启后需要重新录入。请只使用工作台的 API Key 或私密输入框填写凭证，避免放入聊天、应用内容和普通工具参数。

安全设置中的“单次提权检查”仅在管理员显式启用时出现，只执行固定 id -u。它不能替 Agent 执行任意 sudo 命令，也不保存密码。当前没有任意 Agent 私密请求、stdio 密钥注入或通用私密终端。

## 键盘、主题与常见问题

Control/Command + K 搜索，Control/Command + Shift + O 新聊天。弹窗内使用 Tab、Shift + Tab 和 Escape；聊天快捷键不会打断弹窗。手机侧栏是独立弹层，可按 Escape 关闭；跨入手机宽度时会收起原侧栏。

外观可选浅色、深色或跟随系统。默认图表随主题重绘，重绘可能重置 ECharts 的临时缩放/图例状态，历史数据不变。

| 情况                  | 处理                                     |
| --------------------- | ---------------------------------------- |
| 正在加载设置/技能选择 | 可继续等待，或关闭加载提示               |
| 某条内容无法显示      | 先局部重新显示；其他消息仍可使用         |
| 页面或按需资源失败    | 复制未发送草稿后重新加载，不自动重发任务 |
| 配置保存失败或未知    | 在原设置页读取实际配置，按反馈恢复       |
| App/HTML 预览过期     | 明确重新打开；仍需要当前权限             |
| Codex 离线            | 确认服务端登录和配置，再使用重新连接     |
| 历史读取更新过快      | 再次打开对应对话，读取权威状态           |

当前开发范围、能力限制和未完成的上线检查见 [能力清单](capability-matrix.md) 与 [功能冻结记录](feature-freeze.md)。
