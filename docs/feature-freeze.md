# 0.2.0 开发功能冻结记录

日期：2026-11-09。状态：D1–D7 功能开发完成，作为冻结候选版保留；尚未批准正式生产发布。按用户安排，R1 在准备上线时集中执行。

## 范围核对

- [x] D1：受控文件登记、不可变版本、普通文件/图片/HTML/PDF 预览、清理与恢复。
- [x] D2：已发现 Skills 查看、启停、显式选择、原生输入和历史引用。
- [x] D3：Provider/MCP 配置、凭证引用、版本保护、维护互斥和失败恢复。
- [x] D4：MCP Apps Host、逐次工具授权、生命周期与普通非敏感输入。
- [x] D5：固定 A2UI Catalog、Agent 表单、服务端普通草稿和重启只读恢复。
- [x] D6：临时检查、内存/加密保存、Provider/HTTPS MCP 消费、固定 sudo 与输出隔离。
- [x] D7：消息入口、历史/附件/发送恢复、键盘/主题/响应式，以及资源/连接/订阅检查。
- [x] D7.5：能力声明、实际门槛、设置说明和用户指南一致性核对。

实际能力和关闭项见 [能力清单](capability-matrix.md)，用户操作见 [使用指南](user-guide.md)。不接受以“可配置”替代 Provider 全功能兼容，也不把“使用 SDK”描述为支持全部 MCP Apps 权限。

全量 **302 项自动测试**通过。D7.4 新增 11 项连接/资源/缓冲检查；D7.5 新增 3 项服务端能力契约检查。类型、构建和格式检查通过；原有 Codex 生成协议契约仍包含在全量测试中。

本轮未使用用户真实凭证或付费模型。浏览器和资源验证为开发用例；没有把这些数字当作 R1 的完整端到端、24 小时或目标容器测试。

## 仍需处理的发布事项

- [ ] 真实 Linux/Docker、内核 sandbox、持久化、启动/升级与回滚。
- [ ] 固定双域名、HTTPS/Named Tunnel、SSE 与 App origin 隔离。
- [ ] 至少两个真实 Provider 的工具、推理、流式、上下文与错误兼容矩阵。
- [ ] 实际 MCP OAuth、完整业务场景和安全回归。
- [ ] 24 小时、真实并发、全容器内存/CPU、断线和故障恢复。
- [ ] 远程加密备份、匹配加密主钥及完整恢复演练。
- [ ] 最终依赖风险处理、版本锁定、CI 与发布记录。

2026-11-09 的 `npm audit --omit=dev` 仍报告 **2 项 high**：A2UI 核心关联的旧 Zod 与其上游传播项，未提供当前依赖线的自动修复。主要风险是超大集合校验造成资源耗尽。现有入口在 SDK/Zod 之前限制字节、集合、深度和节点，见 [限额记录](a2ui-catalog.md)；这是应用级缓解，不是上游修复或零漏洞承诺。正式发布前必须复核并决定兼容升级或其他处理，证据为 `.data/feature-freeze/audit.json`。

不在当前冻结范围内：任意 Agent 私密请求、任意 sudo、stdio 凭证注入、A2A/ACP、多 Agent、多租户、分布式调度、独立模型网关及插件商店。

## 后续变更规则

R1 前优先处理回归、依赖与验收发现，避免继续扩大功能范围。涉及 Codex 升级时重新生成协议并跑契约/原生检查；涉及资源或连接时回归 D7.4；涉及授权或凭证时回归对应安全用例。生产验收实际结果写入独立发布记录，不覆盖历史开发证据。
