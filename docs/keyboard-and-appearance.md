# 键盘、焦点与主题适配（D7.3）

日期：2026-11-09。D7.3 完成；下一批 D7.4 检查资源加载、缓存、内存增长与重复订阅。正式部署及统一上线验收继续留在 R1。

## 键盘与弹层

聊天输入只响应普通 Enter，Shift + Enter 继续换行。正在组合文字的事件、输入法使用的 keyCode 229、重复按键及带其他修饰键的 Enter 不会提交。登录保留原生密码管理器、粘贴和 current-password 语义。

Control / Command + K 打开搜索，Control / Command + Shift + O 新建聊天。界面根据系统显示快捷键；登录页、菜单和任何弹窗内均不触发聊天导航，避免清掉草稿或打断表单。设置中可查看说明，页面还提供“跳到消息输入”的键盘入口。

搜索、技能选择和重命名明确聚焦输入框；弹窗限制 Tab 范围，Escape 返回，并把焦点交回启动控件。菜单启动重命名时，焦点返回仍然存在的菜单按钮。描述 ID 按实例生成，嵌套弹窗不会共用同一描述节点。文件、技能、App 与私密输入原有的显式焦点返回逻辑优先保留。

手机侧栏使用现有 Radix Dialog 原语管理模态焦点、背景不可操作与 Escape。设置或重命名可叠在侧栏上，关闭后先回侧栏，再回展开按钮；桌面侧栏保持普通导航。窗口进入 760px 以下时收起已有侧栏，避免在已经打开的设置上额外挂载弹层；放大窗口后清除手机焦点限制。

## 布局与主题

- 设置标题和分类始终可达，内容区独立滚动，短横屏也可关闭和访问后续字段。当前分类与对话使用 aria-current 标记。
- 补齐输入框的可见焦点；手机侧栏收起、历史操作、对话行及设置分类按 44px 触控目标处理。手机弹窗中的文本输入、选择器和登录密码使用至少 16px，减少浏览器自动放大。
- 添加 viewport-fit 与安全区留白，保留浏览器缩放；覆盖 320px、375px、667×375 横屏和桌面布局。
- 浅色、深色或跟随系统均保留；显式选择不受系统切换影响，无效历史偏好回退为跟随系统。浏览器 theme-color 同步当前外观。
- 普通次要文字使用语义色变量；默认浅色/深色背景、表面和 hover 表面的次要文字对比度均实测达到 4.5:1。
- Mermaid 与 ECharts 默认画布跟随主题重绘。Mermaid 渲染串行执行并保持 strict 安全配置，避免并发主题初始化串扰；ECharts 释放旧实例和 ResizeObserver，减少动画偏好会关闭默认图表动画。

主题变化只更新呈现，不重新发送模型请求、MCP 工具或表单操作。代码/公式仍使用原有渲染器，MCP Apps 与 A2UI 的主题通道继续保留。普通富文本渲染不再依赖聊天状态模块，因此服务端静态渲染和技能/文件说明测试仍可独立运行。
