# 自动任务的事件触发

在自动任务里添加触发器，选择已安装插件提供的事件来源，连接账号并填写插件声明的条件。平台自身只提供时间触发器，不预置具体业务事件。

所有外部事件经过同一条链路：插件发现和配置 → Bridge 接收及去重 → 自动任务队列 → 该任务绑定的同一会话。插件可以采用轮询、持续连接或经中继交付的 webhook；连接方向和协议由插件适配，平台不识别业务品牌。

安装格式、三种交付方式和开发示例见 [事件桥](event-bridge.md)。已有 MCP 工具插件只有实现事件接口后才会出现在触发器里。

当前只接受 version 2 的事件声明及包含 providerId、connectionId、events、arguments 的触发器。旧专用 webhook 端点、固定来源和 v1 事件适配器已删除。数据库升级会删除不符合当前约定的任务和依赖记录，不猜测或补齐字段；会话正文不删除。已存在的合法插件任务、账号和游标保持不变。
