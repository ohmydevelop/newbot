# 会话工作区与扩展

2026-11-10 开发实现，对应 [issue 03 计划](../.issue/2026-11-10/issue-03-plan.md) 和 [验证记录](../.issue/2026-11-10/issue-03-progress.md)。正式上线验收仍单独安排。

## 使用方式

设置和侧栏统一使用“扩展”入口，分为专家、插件、技能、连接器。插件详情包含它提供的工具连接；独立连接器在自己的分类管理。

专家组合已有技能、已安装插件和连接器的引用，不复制一份插件，也不改变模型或权限。在输入框用 `@` 或扩展按钮选择；每个会话最多一个专家，持续到移除或更换。点击输入框里的专家可查看成员。`$` 技能和单独的插件引用仍只用于下一条消息，和专家的重复引用自动合并。合计最多 8 个技能、8 个插件、专家最多 16 个连接器。

专家的成员被停用、卸载或删除时，目录和详情显示原因，下一轮发送被阻止，草稿保留。删除专家不会删除成员或历史，但引用它的会话须移除或更换专家。全局启用的其他能力仍由 Codex 正常发现；专家是使用偏好的组合，不是隔离或权限白名单。

新聊天首次发送时分配 `DATA_DIR/workspaces/<服务端 UUID>`，空白草稿不创建目录。沙箱可写根、文件浏览、产物捕获和恢复共用此绑定。旧聊天继续使用迁移时的原工作目录，不移动已有文件。归档不自动删除目录。独立目录不等于操作系统隔离；尤其完全访问权限仍具有原生策略授予的范围。

## 配置与生命周期

- SQLite v12 保存网关及手工模型、扩展期望状态、稳定资源身份、专家定义、会话绑定/修订和轻量执行摘要，不另存完整 Codex 对话。
- 新旧线程共用 **newbot 独立** Codex 进程及 CODEX_HOME。宿主个人 `~/.codex`、`~/.agents` 不读取为实例配置、不修改。禁用项目根向上推导，避免工作区祖先说明误进入上下文。
- MCP 普通定义、插件启停和技能启停由服务端 SQLite 发布。首次读取仅迁移可管理、支持的原生定义；管理员/外部只读来源、未知字段及含明文凭证的遗留定义保持原来源，界面显示限制。
- 每轮固定 Provider、审批、专家引用及扩展资源快照。全局更新不打断已执行的任务，下一轮只同步目标空闲线程；原生线程 ID 与历史保留。同步失败回滚已投放资源和已确认快照，用户可重试。
- 已启用的个人/项目技能按原生 `.agents/skills` 格式投放到会话目录，包含辅助资源；路径、大小、符号链接、硬链接及内容变化均校验。项目自行创建的非保留名称技能目录不会被清除。
- 插件包保持原生安装缓存，安装/卸载等修改共享缓存的操作要求实例空闲。技能停用不等于卸载；原生插件在 0.165.0 中仍属演进接口，固定格式契约已经隔离验证。
- MCP Apps 按原线程工具目录授权，已有线程目录时不回退其他线程目录。普通启停不卸载正在交互的 iframe。凭证的加密保存、私密输入和环境轮换继续沿用原私密路径；环境注入所需的受控重连不宣称无重启。

## 产品接口

所有控制仍使用白名单和已登录 Session。

| 入口 | 含义 |
| --- | --- |
| `expert/list` / `expert/read` | 专家、成员摘要、实际可用状态 |
| `expert/save` / `expert/delete` | 创建或按 `expectedRevision` 修改/删除 |
| `session/extensions` | 按 `expectedRevision` 保存下一轮持续专家绑定，执行中的快照不变 |
| `session/update` | 保存会话网关、模型、推理和审批；运行中为候选，下一次发送应用，支持 `cancel: true` 撤销 |
| `session/inputs` | 按修订号保存下一条消息的技能/插件引用，实际派发后消费 |
| `POST /api/agent/run` | 新会话可传 `expertId`；现有会话使用持久绑定，并校验可选 `extensionRevision`；运行快照及幂等记录由服务端创建 |
| `GET /api/workspace/files?threadId=…&path=…` | 相对会话根浏览，不接受任意 cwd |
| `newbot.session.extensions` | 当前会话专家更新，修订号防止迟到响应覆盖 |
| `newbot.activity` / `newbot.activity.snapshot` | 侧栏跨会话执行摘要，不包含对话正文 |

侧栏状态区分准备、运行、待批准、完成、失败、已停止和待确认。`runs.accepted` 只是原生接收执行，不表示任务完成。浏览器关闭后后台继续；服务进程退出后活动摘要先标为待确认，读取原生线程再确认。普通错误通知浮动显示，上传、审批和未知发送结果仍保留就近恢复入口。

网关卡片点击即设置新聊天默认；模型下拉、编辑和删除相互独立。`/models` 不可用时，可在编辑框每行填写一个模型 ID，保存后可执行；手工模型与发现结果分来源显示，不假装已验证兼容性，未知模型可显式选择标准推理档位，但标为待验证；上游接受请求不等于已证明采用该参数。

## 验证边界

`test-extension-native.mjs`、`test-session-extensions-native.mjs`、`test-experts-native.mjs` 使用真实固定 Codex 0.165.0、隔离临时 HOME 和本地模拟 Responses/MCP。验证实际输入、工具目录、线程恢复和进程生命周期；没有调用付费 Provider，不替代真实第三方模型兼容性测试。浏览器截图与自动测试结果位于原 issue 的证据目录。


## 下一轮设置与恢复（Issue 04）

会话返回 `runtime`（已保存意图）、`runtime.applied`（上次确认配置）、`runtime.pending`（待应用/应用中/失败）。`revision` 用于修改与发送校验，`version` 用于状态事件和迟到响应合并。运行时更改不处理原审批；原生设置只在空闲的任务边界应用，同一原生线程和历史保留。

下一条引用通过 `nextInput` 返回。`session/inputs` 接收 `expectedRevision`、技能 `{id,sha256}` 和插件 ID，`POST /api/agent/run` 带 `inputRevision` 与相同的显式引用。失败前不消费；进入派发后按修订号消费，结果未知的请求先查幂等状态，不自动重发。完整未发送正文和附件草稿仍仅属于浏览器；只有已保存候选和引用在服务重启后恢复。

`newbot.session.runtime`、`newbot.session.inputs` 与专家事件用于跨标签页同步；线程恢复时重新读取 SQLite 权威状态。数据库迁移保留原线程、附件及配置。验证见 [Issue 04 进度](../.issue/2026-11-10/issue-04-progress.md)。


## 技能与插件导入（Issue 05）

扩展 → 技能 → 添加技能支持目录上传、ZIP 与公开 GitHub 地址。目录上传无法保留执行位，含可执行脚本时使用 ZIP。来源先暂存并由隔离原生运行时扫描；展示完整分页结果、插件工具与钩子范围，确认后安装整包并仅启用选中的技能。私有 GitHub 内容请先下载为本地包。

安装采用摘要与操作 ID 约束，已安装相同内容默认跳过，替换需明确选择。失败记录可重开，只重试失败包。安装改变共享原生资产，要求实例空闲；扫描可以与任务并行。下一轮生成扩展快照时按包复制共享资源并保留禁用映射，原生线程与已运行任务不变。快照预算为 128 MiB/8192 文件，独立于单条消息的显式引用上限。

导入元数据、选项及恢复日志保存在 SQLite，资源位于 `DATA_DIR/imports` 和实例 `CODEX_HOME`；不会写个人 Codex 配置。最多四份暂存来源，保留 24 小时，全部成功后立即释放；最近导入可手动释放未完成来源。扫描不执行包中脚本、钩子或启动 MCP。服务中断时恢复安装前的资源与配置；需要重新核对的项目显示失败，不把未知状态标为成功。
