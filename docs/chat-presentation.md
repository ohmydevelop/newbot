# 消息呈现与任务反馈统一（D7.1）

日期：2026-11-09。已统一聊天内容与轮次反馈入口，修复当前对话重复报错。D7.1 完成，下一批 D7.2 历史、附件、取消与失败恢复；完整键盘/响应式检查、资源检查及功能冻结仍在 D7.3–D7.5，正式部署验收留在 R1。

## 用户可见的变化

- 当前对话失败只在对应轮次提示一次，流式事件和刷新后的历史使用相同说明。带归属的原生错误通知也进入轮内反馈，不先弹全局提示再重复报错。
- 后台对话需要查看状态时，提供“查看对话”通知；点击只读取该对话。阅读、关闭和事件重放不会创建新任务。通知保留当前连接会话中最近一条，历史事实仍以 Codex 为准。
- 失败轮次提供“重新读取状态”，显示读取进度、成功及局部失败。它不恢复执行、不提交模型 Turn、不重试原任务；用户仍可继续发送消息。
- 附件上传、配置读取等独立错误继续使用全局提示，任务失败不会覆盖它们。没有对话归属的运行错误仍有可见提示。
- 复制回答有成功和局部失败反馈，不再产生未处理的 Clipboard 拒绝；离开消息会清理已有反馈计时器。
- 被拒绝的原生命令显示“未执行”，非零退出码单独显示。工具错误使用普通说明文字，成功结果仍可展开查看。
- 技能说明和文件预览关闭后，焦点返回原消息的操作按钮。手机反馈可换行，状态读取和复制操作保持可点击尺寸。

## 内容入口与边界

`web/components/chat/Turn.tsx` 统一组织消息、文件、运行状态和恢复入口；`Message.tsx` 选择普通文本、技能引用、工具、MCP App 或 A2UI。继续复用已有标准与渲染组件，不增加富文本协议或模型工具。

消息与文件区使用局部显示边界。非法正文或渲染异常会提供固定降级提示及“重新显示内容”，其余消息和输入框保持可用。重新显示只重建对应内容；App 必要的资源读取仍遵守原 Host 生命周期，不自动执行工具或模型。

条目的 React 身份以现有 item ID 保持稳定，内容更新不会反复挂载 App。A2UI 的提交、草稿与只读恢复仍由既有模块处理，文件快照/版本和技能引用保留原归属。后端只补齐带归属通知的状态归并，并在确认完成后清除暂时提示；不改 Codex Loop、配置或持久化 Schema。

后台通知去重缓存最多 128 个任务标识，退出连接时清理，不持久化独立队列。当前模块不是完整通知中心，不自动重发任务、恢复旧 App 授权或赋予旧表单提交权限。
