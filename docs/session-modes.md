# 同会话交互模式

输入框沿用既有权限菜单；没有第二套聊天引擎或额外导航。

|模式|执行边界|
|---|---|
|聊天|直接回答、查看支持的附件、查询经独立确认的只读 MCP；禁用 shell|
|规划|原生 Plan 协作模式，加只读文件沙盒、无网络 shell、已确认只读 MCP|
|工作|既有按需/审查/完全访问偏好、插件、技能、专家、MCP Apps 和 A2UI|

新会话为聊天，迁移的历史会话为工作。模型、推理强度、工作审批偏好和模式共同参与既有会话设置的版本检查。当前任务使用已应用设置，运行中变更进入待应用状态，下一轮再切换；失败状态阻止新任务静默使用错误权限。重启恢复同一约束。技能与专家提示不能提升模式权限。

## 只读 MCP 许可

设置 → 连接器（或插件内连接详情）→ 聊天与规划可用工具。工具搜索、勾选即保存、失败回退和刷新使用公共组件。保存需当前没有任务或授权正在执行。

工具自报 `readOnlyHint` 不能授予权限。用户根据工具行为独立确认后，服务端保存接收方和工具定义的摘要，不保存该接收方凭证明文；接收方、插件版本或定义变化会使许可失效。应用不能证明第三方工具代码绝无副作用，只有已信任、已检查的查询工具才应被勾选。

原生白名单阻止未许可工具被模型调用；已许可工具逐项传入原生 `approval_mode=approve`，兼容没有只读元数据的查询工具。Hooks、notify、原生 Apps、浏览器/电脑执行器、子 Agent、动态工具目录更新等不受此白名单约束的原生通道在只读模式关闭。工作模式保持原行为。Newbot 管理的 MCP Apps 使用标准 Bridge，并在反向调用时再次校验模式、定义和授权版本；未获只读许可的 App 工具需切换工作模式。

接收方指纹在私密参数注入前计算；限制在提供商和私密参数合成后最后施加，避免身份误判或配置覆盖约束。A2UI 仅把已校验表单数据返回当前任务，不直接执行工具，其后的调用仍经过同一边界。

## 验证与兼容性

固定原生版本：`fe2f18520864ddbee86cdd4b103a9fefffe9c6a2`。依赖升级必须重新执行原生基线和产品链路，不以提示词代替权限验证。

- `npm test`：模式迁移、并发、恢复、授权撤销、其他工作会话及已有功能。
- `CODEX_BIN=/path/to/codex npm run test:modes-native`：真实原生 + 隔离模拟模型/MCP，11 项产品边界验证。
- `CODEX_BIN=/path/to/codex npm run test:modes-baseline`：18 个原生行为实验，包含故意开放的危险对照组，不能将对照组算作安全通过项。
- `python3 scripts/test-deployment-database.py`：v17→v18 旧数据保留、错误迁移拒绝、数据库回滚。
- 浏览器模式/工具许可、既有视觉金图、触摸滚动/拖拽/动画检查。没有物理手机验收，不宣称覆盖 Safari。
- `scripts/test-session-modes-live.ts`：必须指定独立、私密的生产数据库副本 `MODE_STAGE_DIR`，使用真实模型及已知只读查询。证据只保存状态，不记录工具返回的业务数据；测试完销毁副本。

本轮真实 deepseek-flash 完成纯聊天及 `list_realtime_events(count=1, period=7)` 查询；这不代表所有模型、所有 MCP、Slack OAuth 已验证。线上不继承测试环境的工具许可。

调查、关联风险和证据见[计划](../.issue/2026-11-16/005-session-modes-plan.md)与[进展](../.issue/2026-11-16/005-session-modes-progress.md)。数据库 mode 新列与版本提升在同一事务内，发布器显式校验旧列内容和历史 work 值，并备份数据库用于失败回滚。
