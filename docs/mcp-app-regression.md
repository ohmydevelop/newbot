# 官方 MCP Apps 交互回归（D4.4）

日期：2026-11-08。D4 的生命周期、Host 能力、普通输入与交互回归已完成。本记录是开发验证，正式目标环境与上线统一验收仍在 R1。

## 可复现的官方示例

```bash
npm run build
npm run test:official-ui
```

使用官方发布的 `@modelcontextprotocol/server-basic-vanillajs@2.0.4`，延续既有固定 tarball SHA-512。准备脚本校验包完整性和提取文件的 SHA-256；测试结束再次检查四个文件。Server 与 HTML 均不改写，Server 只通过 stdio 启动。

浏览器夹具使用独立 Codex 0.166.0、临时 Codex Home 和真实官方 MCP Server；工具发现、资源读取、`get-time` 执行及进程重连都经过原生 App Server。普通输入使用独立的本地模拟 MCP，接受/取消会返回给原始 native 请求。

只有聊天历史由测试适配器重放：一次模拟 Turn 关联两次真实 `get-time` 的原始结果，不创建模型 Turn。重启检查验证原生 MCP 进程重新发现与重放历史的 UI 恢复，不把它当作原生聊天历史持久化或容器恢复证明。现有分享服务的真实原生历史另行验证，见 [服务更新记录](test-service-update.md)。

取消测试从对应 View 发送标准 `notifications/cancelled`，覆盖 Host 对原始请求 ID 的处理；这是测试驱动的协议操作，不声称官方示例自带取消按钮。其他交互调用原版按钮事件，保留原示例的成功/错误显示方式。

## 本批修复

此前不同 View 可能同时打开授权框，App 的协议取消也没有同步到 Host 的待审批状态。现在同一页面只有一个 App 工具授权决定；其他 View 收到固定的忙碌结果，完成当前决定后可明确重试。不增加后台队列或自动重放。

这一限制只覆盖等待授权的阶段。单次批准完成后释放该页面的确认位置，已批准执行可以并行。明确发起新操作时清除上次操作的提示。服务端仍逐次校验 Session、来源 Server、UI 资源关联、App visibility 和单次 grant，客户端的提示不代替服务端授权。

| 取消发生时机         | 实际处理                                                                     |
| -------------------- | ---------------------------------------------------------------------------- |
| 工具权限发现尚未返回 | 立即释放确认位置；迟到的 grant 被撤销，不产生迟到授权框。                    |
| 授权框正在等待       | 关闭对应决定，撤销未消费 grant，不调用原生工具。                             |
| 已批准并提交执行     | 提示已取消等待、工具可能继续；不把协议取消冒充执行中断。                     |
| View 关闭或卸载      | 清理该 View 的等待状态；旧操作的迟到清理不能释放其他 View 新取得的确认位置。 |

授权框关闭后适当返回对应 iframe 或重开按钮；若用户已转移焦点到其他控件，或另一个授权框已打开，不抢回焦点。普通输入仍是独立的原生请求：App 的操作和关闭不会提交或取消另一个 MCP 服务的表单。

## 18 项官方示例检查

覆盖以下流程：

- 两个 View 的初始化、不同原始结果关联、拒绝后重试、反复关闭/重开及旧资源 URL 失效。
- 同一 View 的重复请求、跨 View 的单一确认、批准后的并行执行，以及 grant 不能重放。
- 发现中、待审批中及批准后的三种协议取消；取消后没有隐藏授权阻塞维护。
- 原版消息、外链和日志控件的受限行为；伪造另一个 Server 的工具仍被拒绝。
- 真实普通 MCP 输入与 App 同时工作，保留表单草稿和独立响应；App 关闭不会取消无关输入。
- 资源失败重试、浏览器刷新、真实 Codex/MCP 重启、不同 Web Session 的租约归属。
- 桌面浅色与手机深色、sandbox 和网络边界；文件校验及无模型调用。

本轮结果是 152 项自动测试、18 项新增官方示例浏览器检查，以及 19 项生命周期、14 项 Host、15 项普通输入回归通过，共 66 项相关浏览器检查。类型检查和构建通过。

证据为 `.data/official-app-ui/result.json`、桌面/手机截图及 `.data/d4-4-*.log`。矩阵结束时没有残留 View 或普通输入；原版文件校验一致，浏览器无 pageerror、外部请求、弹窗或下载，合成消息/链接/日志标记没有进入夹具服务端日志。工具调用为只读时间查询和模拟输入，不调用模型。共享服务的真实历史与 Cloudflare 取消/重开检查也通过，未执行模型或 MCP 工具，见 [服务更新记录](test-service-update.md)。

本记录只覆盖固定的官方基础 Vanilla JS 示例与已实现的 Host 能力，不代表所有第三方 App、外部依赖、网络权限或长任务都已兼容。上游工具和 App SDK 自身的超时仍有效，已批准操作在断线或取消等待后可能继续。下一阶段进入 D5.1，核对 A2UI 的实际版本、Schema 和官方最小样例。
