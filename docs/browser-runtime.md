日期：2026-11-09。D7.4 完成，下一批 D7.5 核对真实能力、使用说明及功能冻结。正式环境部署、24 小时和全容器资源验收继续留在 R1。

## 修复与边界

- 连接具有独立代次。关闭连接会终止对应请求，废弃旧配置、列表和历史读取；迟到能力、事件、审批与旧 Session 检查不能覆盖新连接，也不能注销后续登录。SSE 重复 open 回调共用一次状态同步，重复 connect 不增加连接。
- 初始化 Session 检查支持取消，React StrictMode 和页面卸载后的迟到结果不会恢复旧状态。浏览器偏好存储已满时，更新聊天状态仍可继续。
- 读取历史期间的事件缓冲最多 1024 条或约 4 MiB 字符预算。超过预算会释放缓冲并只读核对一次权威历史；再次超出时提示用户读取状态，不自动重发任务。
- 空闲时释放其他对话的空草稿记录，保留文字、附件和技能选择；上传、发送或发送未确认期间不清理相关记录。用户明确加载的历史和非空草稿仍保留在当前页面内存，退出或刷新后释放，未设置会丢弃输入的全局硬上限。
- 设置和技能选择按需加载时显示进度并允许取消。资源失败保持局部可见、保留输入区，提供明确的页面重载入口；重载前提醒复制未发送草稿。已缓存的模块失败不再提供无效的局部重试。
- 图表资源失败与语法问题分开处理；普通畸形消息继续使用局部“重新显示内容”。事件协议组件加载失败会停止自动重连循环，提示重载。
- 离开的 Mermaid 等待任务跳过渲染；图表实例、ResizeObserver、弹窗监听及主题订阅按既有生命周期清理。性能探针仅在 `?profile=1` 启用，重复安装不会创建第二份探针。

## 构建与缓存

静态资源继续使用带内容指纹的文件名和 immutable 缓存，首页使用 no-cache，接口/私密内容使用原有 no-store 策略。新版本在独立目录完成后发布，保留上一代不同内容的资源；无改动构建不提前淘汰这一代。下一次不同内容的发布只保留最近两代，不承诺无限期兼容从未刷新的旧标签页。

保留资源路径严格限制在 assets 目录，压缩副本可复用；Brotli/gzip 协商与解压一致性沿用自动测试。静态发布目录使用 0755，避免临时目录的 0700 阻止另一运行用户读取。该权限检查不等于已经运行 Docker。
