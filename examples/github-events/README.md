# GitHub 仓库事件

通过 newbot 的插件导入安装本目录，随后在自动任务的“添加触发器”中选择“GitHub 仓库事件”。支持 Issue/PR 关闭、重新打开、添加/移除标签、指派/取消指派成员。

连接事件账号时，私有仓库使用带 Issues 读取权限的 fine-grained token；公开仓库可以留空。此凭证仅用于 api.github.com，不复用 MCP、模型或聊天凭证。不要把令牌写进插件文件或任务指令。

每分钟左右主动检查，无需公网回调。首次连接建立基线，只处理之后可读取的事件。重连发现历史缺口会停下提示，不自动跳过。首次连接、切换账号或暂停后恢复会重新建立基线；恢复前的历史不自动回放。

这是 Newbot 事件扩展，不是 Codex/MCP 官方通用事件协议。仅覆盖上述 Issue/PR 事件，不包含新建、评论、Push、CI 等全部 Webhook 能力。不支持 GitHub Enterprise、自定义 API 地址或任意插件脚本。
