# 网关错误可诊断性与切换反馈

## 用户目标与证据

GE-01：网关欠费时长时间等待后只显示“本次任务未完成”，读取状态仍没有原因。用户已确认欠费，但原始响应尚未核实。截图保持原附件不变：`/home/a/.codex/attachments/4122f75f-d5ba-492b-b4e2-24531ac1d8c3/codex-clipboard-9b11ec57-702b-4c92-810b-e3cb8693ebdd.png`。
GE-02：运行中切换显示“此模型缺少…能力信息”，不知道是哪个模型、不知道如何继续，旁边“重试”实际只刷新目录。截图：`/home/a/.codex/attachments/53cbb758-0900-42cf-80ab-3a9d4d73092a/codex-clipboard-d4b59284-3bed-4d43-8926-26d5c25e1266.png`。

不变量：可用错误原因必须贯穿实时事件和历史恢复；欠费、额度、频率限制、认证、网络和未知错误不能混为一谈；不把上游响应中的密钥、请求正文、URL等泄漏到浏览器。自动重试须可见，但不能误作任务最终失败；恢复状态不重新派发。模型切换拒绝时保持原线程、任务与配置，不绕过原生能力守卫。

## 根因与同类风险

|范围|判断与证据|处理|
|---|---|---|
|实时错误、完成失败|有代码证据：ag-ui.ts 固定文案且忽略 willRetry 错误|统一分类与安全诊断；自动重试可见|
|历史恢复|有代码证据：view.ts publicTurn 丢弃 error 全部原因|与实时使用相同分类|
|聊天呈现|有代码证据：turnFeedback 忽略 error.message|主消息原因+下一步，按需展开诊断|
|原生 RPC 失败|有代码证据：codex.ts 所有非切换错误被泛化|已识别原因使用同一分类；未知不透传原文|
|切换元数据拒绝|有代码证据：step_activation.rs 区分 active/destination，bridge 合并为“此模型”|区分当前/目标、说明等待结束/停止后切换；保持检查|
|选择器重试|有代码证据：错误共享 state，重试仅 read(true)|目录错误与设置错误独立；目录按钮明确刷新，切换错误无假重试|
|目录包含嵌入/重排模型|截图有证据，目录只有 ID 不能证明任务兼容性|不按名称黑名单或凭空补元数据；本轮解释能力边界，完整目录能力声明另行处理|
|MCP工具内部业务错误|不同接收方和权限路径|不把业务工具文本直接作模型网关错误；本轮不扩为工具全量错误重构|

## 阶段与验收

1. S0 记录并核对当前运行/构建；查看可用原生错误的脱敏统计。
2. S1 安全错误投影：只输出固定分类文案、建议、允许的数字 HTTP 状态和已知错误码；实时、重试、历史与 RPC 一致。覆盖欠费明确证据、额度/429不误报欠费、401/403、5xx、网络、上下文及未知。未知明确“上游未提供可识别原因”，保留任务 ID 便于定位，不泄露原始正文。
3. S2 前端就近展示原因、操作建议及折叠诊断；自动重试不显示最终失败；切换区分对象与动作。浏览器桌面/手机验证，读取状态不增任务数。
4. S3 类型、构建、相关回归，更新开发服务并核对公网一致。服务端改动仅在没有运行任务时重启；否则记录待生效。

无数据迁移；兼容旧事件/旧历史无诊断字段。历史原生已保存的错误可重新读取恢复原因，但无法凭空恢复已被上游或旧持久化层丢弃的数据。不修改外部网关计费，不放开内核能力约束，不执行真实业务调用。模拟证明错误链路，不证明真实 Provider 兼容。

状态：S0/S1/S2/S3 已实施并完成针对验证。证据目录 `evidence-gateway-errors/`，进度 `gateway-errors-progress.md`。

S1 补充：实时通知与最终失败可能不是同一条错误；终态缺少原因时保留已识别诊断，不覆盖为未知。SQLite metadata 按会话/任务保存安全失败摘要（不保存原始响应，不复制历史），恢复时补齐；成功或明确用户停止清除暂态摘要。使用现有表，无 schema 迁移。验证重开数据库、跨任务不串和完成清理。

关联检查补充：provider/models 与 provider/test 在读取响应正文前一律丢弃失败响应；session-runtime 目录 catch 再次泛化（有代码证据）。纳入相同安全分类：限额内只解析 JSON error 的 message/code，HTTP 状态始终保留，不展示原文，HTML/超大/损坏响应仍受控。目录读取继续不影响本地保存。

## 完成与限制

57 项回归、类型与完整构建通过；开发服务已更新，公网/本地前端产物一致。具体见进度与 evidence-gateway-errors。原截图所对应上游原始响应未能从最近 rollout 找回，旧历史若缺少原始错误不能凭空恢复；新错误开始保留安全摘要。模型元数据缺失的原生限制仍然存在，本轮改正说明与交互，不称已让未知模型通过热切换验证。目录中的嵌入/重排模型仍需上游任务类型元数据才能作可靠的统一筛选；本轮没有按厂商名称特判。
