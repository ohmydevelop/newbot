|编号|触发与实际行为|预期与不变量|
|---|---|---|
|AT-01|打开 MCP App，入口数据可用，但 UI 调用普通业务组工具失败|界面来源关联与后续工具调用权限分开判断；同一 MCP 连接中对 App 可见的数据工具不必绑定相同 UI 资源|
|AT-02|其他标准 App 的刷新、分页、详情等数据工具未附 resourceUri 或使用其他资源|应用工具目录依据同一连接和 visibility；不依赖某个外部插件名称或业务结构|
|AT-03|目录变化、权限撤销、连接禁用、跨会话/浏览器、重放审批|每次申请与批准均重新校验；不跨 Server，不绕过逐次授权，不复用过期租约；原始 UI 资源必须仍关联来源工具|
