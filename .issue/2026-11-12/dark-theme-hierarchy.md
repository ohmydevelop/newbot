# 深色模式层级：画布最暗、侧栏中性灰

日期：2026-11-12。用户要求：深色模式下左侧栏改为灰色，右侧聊天区用原来左侧的深黑色，并选择“保守”方案。

## 结论与理由

把原有的「侧栏更暗（#171717）/ 画布较亮（#212121）」改成 IDE 式层级：**画布最暗（舞台），侧栏退一档为中性灰（工具区）**。这与浅色模式逻辑一致——画布始终是极值（浅色最亮、深色最暗），chrome 向中性靠；切换主题时层级不会翻转。

## 改动

| 位置 | 旧值 | 新值 |
| --- | --- | --- |
| `--bg`（聊天画布） | `#212121` | `#1a1a1a` |
| `--sidebar` | `#171717` | `#262626` |
| `--hover` | `#3b3b3b` | `#383838` |
| `--menu-bg`（弹层/抬升面） | `#282828` | `#2d2d2d` |
| `--code`（代码块） | `#171717` | `#202020`（避免与画布同色） |
| `--on-strong` | `#1a1a1a` | 不变 |
| `.modal` / `.approval-card` / `.artifact-card` 背景 | `var(--bg)` | `var(--menu-bg)`（浅色下二者同为 `#fff`，无变化；深色下不再沉进画布） |
| `meta[name="theme-color"]`（深色） | `#212121` | `#1a1a1a` |

只改 `web/styles.css` 与 `web/App.tsx` 的 theme-color；未动布局、字体、间距和其他主题变量。
