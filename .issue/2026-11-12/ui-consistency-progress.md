# 交互一致性：实施记录

对应计划：`ui-consistency-plan.md`。日期：2026-11-12。

## 改动

### 侧边栏对话行

- 结构改为 `标题 · 相对时间 · 动作位`。动作位固定 30px，状态图标与“⋯”绝对定位重叠：默认显示状态，`hover` / 键盘聚焦 / 菜单展开时状态淡出、按钮显示。实测两者同一 x 区间、无布局跳动（`linkWidth` 保持 208px，动作位 30px）。
- 状态改为图标式：等待态显示时钟 + 数字徽标，完整文案仍在 `title` 与 `aria-label`；原先固定 76px 的空列与文字挤压消失。
- 触屏/无 hover 环境（`@media (hover: none)`）：状态与“⋯”并排常显，动作位 72px，实测不重叠。
- 新增 `web/time.ts`：`relativeTime()` 显示“刚刚 / N 分钟前 / N 小时前 / N 天前 / N 周前 / 月日”，`absoluteTime()` 作为 `title` 精确到分钟；时间每行常显、次要色、等宽数字。

- Provider、Skills、Plugins、Experts 的行内动作区已全部是图标按钮；混用只出现在 MCP 详情，已修。
- 其余 `查看详情` 命中共 3 处（MCP / 插件 / 专家），全部统一。
