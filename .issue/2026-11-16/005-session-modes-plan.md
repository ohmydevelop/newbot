# MODE-1 聊天、规划、工作模式

## 用户目标与约定
保留 Grok 风格界面和全部插件、技能、专家、附件、MCP Apps/A2UI，以一个 Codex 运行时实现同会话切换。聊天允许经审核的只读资料查询，规划允许沙盒内只读调查，工作使用既有授权。模式不能静默提权；保存、重启、恢复、迟到回执均不能丢失限制；运行中修改只作用下一轮。新会话聊天，历史会话工作。

## 调查与根因
6371ff6 为干净开发基线，线上产品 b612951。原生 Plan 是提示不是权限边界；只读文件沙盒不约束直接 MCP、Hooks、notify。原生 allowlist 有效但重启不自动恢复。当前运行设置缺少 mode，Apps grant 无 mode 绑定。已完成 95 项现有测试和 18 个原生隔离实验，见 evidence-modes；模拟上游不证明真实模型质量、延迟或第三方兼容。

## 实施范围与顺序
1. 固化隔离实验和计划。2. 持久化 mode 和审核工具策略；最后合成有效策略，封住公共执行入口，恢复时重放。3. 增加紧凑模式控件和实际权限/待应用状态。4. 原生、服务端失败边界及浏览器验收。5. 真实只读服务验收、备份部署和公网核验。
不引入第二聊天引擎、不修改原生内核、不重构旧界面。历史数据库缺 mode 归工作；pending 旧记录同样归工作。工具许可绑定连接器身份和定义，未知/变更默认拒绝。保留工作授权偏好。

## 验收
同线程历史/附件不丢；新旧会话默认符合约定；CAS 冲突和运行中切换不覆盖当前任务；恢复/重启重放；无许可或误标工具不能越权；Apps 旧 grant 失效；A2UI 只返回数据，后续工具仍受策略；工作会话保持原行为。浏览器 320/390/1280、浅深色、键盘、滚动、拖拽、减少动效，沿用金图。真实服务测试单列证据；模拟和无真机限制明确。

调查、产品实现和所列本地验收完成；待提交部署和公网复核。进展与证据见 005-session-modes-progress.md。

## 发布迁移补充
现有发布器逐表 SELECT * 比较，会将 mode 新列认定为数据损坏；失败回滚只恢复 bundle，不恢复已升级数据库，旧服务不能可靠读取 v18。证据：scripts/deploy-verified-web.py summaries/except。发布前增加显式 session-modes-v18 迁移选项：限定 v17→v18，按原列比较旧数据，校验所有旧记录 mode=work；停服后备份；迁移失败恢复数据库和原 bundle。默认无迁移发布保持严格全表比较。以临时 SQLite 测试正常迁移、旧数据变化拒绝、错误版本拒绝及备份恢复。
