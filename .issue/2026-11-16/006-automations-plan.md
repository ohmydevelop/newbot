# AUTO-1 自动任务：Grok 对照与实施计划

## 用户目标和预期
用户要求认真研究 grok.com 自动任务，尽可能还原其设计理念、功能与视觉交互，入口固定为新建聊天下一行。保留旧版聊天、插件、技能、专家、附件、模型和权限，不引入第二 Agent 引擎。

## 实施顺序与范围
1. 保存官方功能/视觉对照与边界；在既有设计系统内建立新表面约定。
2. 类型/SQLite任务与运行表；Temporal日历；复用公共run路径；调度幂等、CAS、单任务不重叠、暂停恢复、停止、删除、分页记录、独立会话。
3. 侧栏新建聊天→自动任务→搜索聊天；任务列表/模板；创建与编辑按触发器→指令（附件/扩展/模式）→通知；概览/运行记录，立即运行、未读和打开完整会话；从当前聊天内容创建任务草稿。
4. 用户未指定外部通知通道前，默认站内通知与用户主动启用的浏览器提醒；邮件触发/外发邮件列为对齐差距，不展示不可用按钮冒充实现。预留受认证事件接入边界；不擅自配置邮件账号、发送消息或创建公网真实周期任务。
5. 行为测试、浏览器和真实隔离模型验收；发布前记录明确的功能对照和剩余外部依赖，不用“1:1”掩盖实测缺口。

## 调度语义
按任务时区的墙上时间；DST缺失时间顺延、重复时间取首次；每月31日/每年闰日跳过不存在日期。服务停机后仅补最近一次到期，跨多个触发器同一时刻合并；同任务正在运行时合并等待，避免重叠。不自动重试已经派发但结果未知的任务，显示中断/待确认和原会话入口。暂停阻止以后触发，正在运行需单独停止。删除停止以后触发，保留已生成聊天与历史快照。

## 不处理
不改品牌/全局字体配色；不直接使用Codex桌面自身的automation工具创建用户任务（这是开发Newbot功能）；不引入Redis/独立微服务；不自动绕过现有工具或第三方OAuth授权；不宣称物理手机或实际邮件触发已验收。

## 完成条件与记录
原生/HTTP的日程到期和立即运行都走现有公共提交路径；计划保存重启恢复；权限/重复/取消/时区边界有测试；UI截图与交互证据；已接通和受限功能分列。进展见006-automations-progress.md。初始状态为调查阶段；本轮实现、验证和发布已完成，具体结果及外部限制见进度文件末尾。

## 本轮补充：邮件与弹层（2026-11-16）
用户已明确要求邮件通知。新增 A9：SMTP 配置加密保存、只返回已保存状态；站内/邮件/两者/无四种通知。任务结果与邮件 outbox 分离，固定收件人由实例管理员配置，邮件仅含任务状态和结果入口，不附模型上下文或凭证。投递失败可单独重试，不重新运行任务；发送中断标记待确认，不自动重发。SMTP 使用 Nodemailer 的 TLS/STARTTLS，禁用任意文件/URL 内容读取。私有 CA 可配置，不能关闭验证。测试使用本地 TLS SMTP 接收器，外部邮箱实际送达需用户配置后验证。
浏览器已复现 A7：共享 PickerContent 的 z-index 65 小于 Modal 111，频率列表虽出现在可访问性树却被遮罩挡住。共同机制涉及 Modal 内模型、模式、时区、技能和插件选择器；通过共享弹层上下文修正层级，只提升处于 Modal 内的 picker，不全局提高所有浮层。验收真实点击、Escape 逐层关闭、滚动和焦点恢复。

## 发布依赖与剩余对照范围
SMTP/Temporal 使用已安装并锁定的 npm 包，不另造协议或日历引擎。新增运行依赖随 `dist/server/node_modules` 一同生成、计算散列和发布/回滚，避免生产源码落后时缺包，也不替换生产旧分支的共享 node_modules。
当前对齐范围是时间触发自动任务、扩展与附件、执行历史、站内/邮件通知及聊天草稿创建。Grok 的邮箱收件事件触发、聊天自然语言自动创建任务、网页关闭后的系统推送，需要另行真实来源/宿主推送接入，不能将站内轮询或模板视为这些能力已完成。

## A7 关联缺陷：展开工作流程滚动竞争
全量浏览器第 40 项复现：内部已设 scrollTop=180，滚轮100后实际100，而非大于180。代码证据：ProcessGroup useLayoutEffect 依赖每次父渲染生成的 items 数组，每次都将 DOM scrollTop 恢复为 onScroll 尚未来得及更新的 position.current。新增自动任务轮询增加父渲染机会，原有其他设置/侧栏/流式更新亦共享机制。约定：只有由折叠变展开时恢复历史位置；已展开且用户离开底部时，普通重渲染不得写入滚动位置。修复共同组件，运行中且处于跟随底部状态仍允许新内容跟随；折叠时忽略隐藏元素的滚动回调。补充同一浏览器 JS 事件中设置滚动并触发侧栏变化的确定性验证，以及原两端交接/重开位置测试。
