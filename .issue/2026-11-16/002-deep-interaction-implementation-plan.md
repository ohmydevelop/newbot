# Issue 002 实施轮：统一深层交互（UI14）

用户已授权按002分析计划修复、补齐自动/浏览器验收并上线。本轮继续codex/newbot-systematize，起点ce1e749；生产入口和旧版设计token不变。原始证据、八项因果链及同类风险清单见002-deep-interaction-analysis.md，本文件补充实施决策，不覆盖历史分析。

## 约束与范围
修复B标签、D目录主行对齐、E稳定详情操作及技能菜单、F工具详情滚动、H显示名；C统一四目录加号。A当前通过的专家滚动和G模型搜索作保护项；同机制扩展至模型默认状态、专家不可用状态/长详情、插件MCP/技能和历史技能阅读、导入技能选择器。危险操作仍确认，实际能力/权限不扩展。连接器稳定ID、执行与凭证引用不变，无数据库迁移。保持既有字体栈、色彩、内容宽度及100/180/300ms动效；不进行框架或聊天布局重构。

## 实施顺序
1. 增加数据映射及深层UI行为回归，记录旧版本失败证据；保留已通过滚动/搜索基线。
2. 修复专家显示名/错误提示，详情脱离旧卡片高度，内部选择窗允许边缘滚动。
3. 共享添加控件、主行尺寸与操作槽；技能菜单；详情标题操作与稳定模式切换；关键表单可见标签。
4. 扩展结构lint、故障注入验证；浏览器覆盖真实形态数据与加载/失败/切换/返回，检查相关配置与权限边界。
5. 本地类型、单元、设计、完整浏览器回归，审查桌面/窄屏明暗截图及录像（不得静默更新旧基线）。提交推送，检查CI结果；若外部CI仍不可运行，以有证据的本地门禁发布。
6. 备份生产dist与数据，部署通过验证的前后端，重启同一服务，核对公网manifest/资产、真实目录名称与交互。变更后端前核对与线上旧bundle差异；不覆盖.env、原生runtime或用户配置。失败回滚备份。

## 验收
- 有/无描述、长名称的状态与更多操作中心差<=1px；同类目录一致，描述单行省略，主体按钮和更多不嵌套。
- 说明/源码、加载/失败/恢复不会推走主操作；技能/专家主操作在正文之前，手机操作区域稳定；菜单启停/卸载具有反馈和正确权限。
- 125工具详情走主滚动，无224/244px小窗口；专家/导入选择窗中段隔离、上下边缘交接、背景不滚。
- 名称重命名/重名/停用/缺失有覆盖，ID和存储引用不变；模型搜索保留。
- 持久字段标签填值后仍可见；证书、私密字段、插件MCP配置原能力可访问。
- 四宽度320/390/768/1280及明暗布局，键盘、reduce motion、拖拽和聊天流程已有回归不退化；真机和Safari未测需明示。
