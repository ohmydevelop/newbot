# NB-UI-12 实施基线（2026-11-16）

用户已批准本计划实施。沿用001调查及原始证据；本文件记录后续明确的产品决定，不覆盖历史分析。

## 目标、不变量与范围
保持已认可旧版聊天体验和全部业务能力，规范组件、导航状态、动效、拖拽及发布门槛。原问题：关闭控件独立绝对定位产生5px中心差；分类真正挂载后往返清空查询；插件底部入口与聊天历史混淆；检查与发布未关联。调查证据及同类风险见001-ui-drift-analysis-plan.md。

## 已确定的产品决定
- 独立插件入口从展开侧栏、折叠栏、手机抽屉删除；设置保留清楚的文字/图标入口。
- 设置一级顺序：外观、操作、连接器、技能、专家、模型服务、存储、安全。连接器内管理商店及导入；不再出现第二套三个分类tab。输入框快捷选择保留。
- 设置共享标题栏拥有搜索/新建/刷新/关闭布局，三分类共同修复；手机分标题及操作两行。几何中心偏差≤1 CSS px，手机点击区域≥44px。
- 导航状态按分类保存query/filter/scroll/focus，在应用内关闭重开保留，刷新清空；凭证/表单草稿不缓存。请求生命周期保留原operation scope取消/隔离。
- 左侧256默认，范围220–400，折叠57；右侧300默认，范围260–520。统一pointer capture/RAF/取消/失焦/键盘/持久化；方向键10px，Home/End边界。空间不够时优先缩右再缩左，再使用覆盖层。手机继续抽屉。
- 保留原字体角色/温黑及浅色/752内容宽度；反馈100ms、面板180ms、导航300ms，正常动画和reduce-motion分别验证；已选能力继续由侧栏承载。

## 实施顺序及依赖
1. 写已复现行为的失败检查，固定fixture/browser依赖及视觉环境。验证当前失败而非直接写通过测试。
2. 统一设置容器、标题栏、目录状态；迁移原有入口，兼容plugins/mcp→connectors。
3. 共享调宽实现、指针收尾、键盘、动效/滚动；消除替代的旧CSS/控件，禁止新增平行实现。
4. 静态边界、视觉几何/流程/动效/性能检查接CI；注入5px偏移和查询丢失必须失败。截图不自动升级golden。
5. 同一构建生成验证receipt和release manifest，发布前阻止失败/缺失/哈希不匹配。备份、原入口部署并核对运行资产及配置。

## 验收及兼容
1440/1280/768/390/320、浅深色；目录切换须等待lazy完成；慢读/失败/迟到、详情及焦点返回。发送/附件/工作流程/滚动锚点/取消恢复原有约定继续。拖拽两侧、iframe跨越、capture丢失、键盘、重载恢复；固定长会话fixture，本地反馈p95≤100ms、拖动≤2帧。静态截图不当动画证据，模拟上游不当真实服务兼容证据。

无服务端业务API或数据库迁移；内部SettingsSection/CatalogViewState/调宽接口新增，右栏旧偏好兼容。CI使用成熟ESLint/Stylelint/Playwright与已有夹具，不引入新聊天框架。既有技术债按受控范围逐步减少。
