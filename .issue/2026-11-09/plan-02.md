来源：[2026-11-09-02.md](2026-11-09-02.md) 及其 7 张参考图。目标：设置更紧凑、凭证操作完整、工具与插件统一管理、技能条目化，并统一图标与适度配色。保留现有会话、文件、私密输入隔离与应用生命周期；正式上线验收继续留到 R1。

| 阶段              | 状态   | 实施与验收                                                                                                                                                                                                           |
| ----------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B1 编辑器规范     | 已完成 | 统一弹窗内容边距、宽度、滚动和操作栏；保存按钮简称保存、关闭用 X；清除、删除等需要确认的操作保留必要确认。                                                                                                           |
| B2 网关与凭证     | 已完成 | 移除列表表头、内部 ID 与常驻连接详情，刷新图标置于 + 后；点击编辑查看详情。新增自动唯一 ID；名称/地址/API Key 在一个表单保存，密钥只经私密通道提交，配置只存引用；编辑可保留、替换、清除，部分生效和断线结果可恢复。 |
| B3 统一工具页     | 已完成 | 合并插件与独立 MCP 管理入口，统一搜索、条目详情、添加和更多操作；插件内工具归属于插件详情，避免重复管理；保留 OAuth、启停和只读来源限制。                                                                            |

| B5 视觉与回归     | 已完成 | 统一图标尺寸/对齐，添加类别色与选中/状态色；桌面、手机和深浅主题截图验证。类型、构建、针对性测试与既有会话/凭证/应用回归通过后更新测试实例。                                                                         |
