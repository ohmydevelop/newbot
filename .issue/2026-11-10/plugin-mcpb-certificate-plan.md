## 声明契约与边界

- 插件可在根目录携带完整 MCPB `manifest.json`；多个连接器可以分别携带包内子目录的 `manifest.json`。
- 仅发现明确包含受支持 `manifest_version` 的 MCPB 清单；必需字段包括 name/version/description/author/server，server 含 type/entry_point/mcp_config。`name` 与原生 mcp.json 连接器标识一致，重名、越界或不存在的关联拒绝。
- `${__dirname}` 相对于该 MCPB manifest 所在目录，entry_point 必须存在且位于其连接器包内。保持原生插件清单、技能和 MCP Apps。
- MCPB 是标准描述；“在 Agent Plugin 内按 MCPB name 对齐原生 MCP ID”的发现策略是宿主实现，不宣称 Codex 或其他宿主自动支持嵌套组合。
- 不读取、不迁移 io.newbot；旧格式明确拒绝，重新导入前要求作者更新。无用户配置的原生插件继续运行，不强制具备 MCPB。
- 本轮证书获取输出服务器完整证书 SHA-256 指纹及证书信息。插件声明普通字符串字段接收指纹；宿主不根据业务变量名硬编码。对只有一个 URL/目标文本字段的表单简化选择，多字段明确选择，不能猜测用途。
- 仅 HTTPS 有 TLS 证书；输入 HTTP 不自动跳转/猜测端口。目标来源于当前连接器公开字段，展示域名/端口。允许明确输入的私网地址，拒绝回环、链路本地、云元数据、多播等禁区；DNS 结果固定后连接，限制超时/并发/响应大小。
