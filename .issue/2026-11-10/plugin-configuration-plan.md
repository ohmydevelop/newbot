# 插件内连接器与技能统一配置：调查及实施计划

## 用户目标与当前边界

用户已自行导入 CloudWalker，希望在插件详情中统一管理连接器、技能。插件预先定义启动命令、参数及字段映射，最终用户只填写所需的平台地址、Key 等业务设置；不同连接器可以要求不同字段，无需配置的连接器不生成空表单。

前轮已完成实际安装核实、配置标准调研、隔离原生探针和方案落盘。本轮用户明确授权完成修复，并要求插件组件不出现在独立技能等管理目录。本计划继承 SQLite 配置持久化、私密输入、下一轮参数热更新、个人 Codex 隔离及固定 Codex 0.165.0 的约定。

## 本轮实施细化（编码前补充）

- 配置描述沿用 MCPB `user_config`；原生插件以 `extensions["io.newbot"].version=1`、`mcpConfigs.<server>="./配置文件"` 关联包内 MCPB 描述，明确这是宿主关联扩展。已有 CloudWalker 原始包使用严格绑定已核实包摘要的兼容描述，不修改原包、不按任意同名插件猜测字段。
- 添加 SQLite v14 插件连接设置表，按插件 + server 的稳定身份保存普通配置、启停、Schema/包摘要及修订。秘密继续通过私密二进制通道和现有加密库，设置与秘密在一个事务提交，覆盖丢失响应查询。
- 仅对需要适配的受控导入包生成插件归属的 MCP 运行参数：稳定内部名称避免不同插件同名碰撞，原生插件同一连接器禁用以防重复启动；它不是独立用户连接器，不进入普通连接器编辑/删除接口。工具执行仍由 Codex 原生 MCP 客户端承担，状态记录宿主归属，不能冒充原生返回的 pluginId。
- 运行快照记录包/配置身份及普通值，敏感值只在原生派发边界解密；接收方或包内容变化后旧凭证失效。保存只影响下一轮，现有运行不重启。
- 公共独立技能目录、`$` 候选、专家可选技能排除插件组件；插件详情提供技能说明与启停。原生运行扫描保留完整插件结构，历史执行记录不伪造改写，旧选择需要兼容处理。
- 补充验收：两个同名 MCP 的插件互不覆盖；独立 MCP 不能编辑插件目标；未知包、错误描述、更新摘要、秘密清除及插件停用均不泄漏或静默启用；所有子组件只在所属插件中出现。

证据目录：`evidence-plugin-configuration/`。当前服务资源 `/assets/index-nylPB7D1.js` 与本地构建一致。安装记录为 `cloudwalker-0.5.0-linux-amd64 (1).zip`，不是前轮生成的本机兼容包；不将这点解释为用户操作错误。

## 标准调研与选型边界

1. **MCPB `manifest.json` 的 `user_config`** 最贴近本地插件安装体验：类型、标题、帮助说明、必填、默认值、敏感字段；通过 `${user_config.KEY}` 绑定 `server.mcp_config`。适合 CloudWalker 这种已打包本地 MCP。
2. **MCP Registry `server.json`** 支持环境变量、参数、HTTP headers、URL 模板变量及 `isRequired`、`isSecret`、`choices` 等。适合注册表发现和远程连接器配置描述，不是业务工具输入协议。
3. **MCP Authorization / OAuth** 处理远程授权，不能代替任意插件安装设置 Schema。支持 OAuth 的连接器保留“连接账号”流程；无需用户输入的连接器不要求填写 Key。
4. **OpenAI/Agent Plugins 外层包** 继续负责技能、MCP 与资源归属。当前 OpenAI 文档明确不执行 Claude `userConfig` 安装提示或展开其变量；不能直接把 MCPB 字段塞进原生 `plugin.json` 并期待 Codex 生效。
5. **JSON Schema** 可用于内部校验，但其本身不规定密钥保存、模板绑定或如何注入进程。不要将自行发明的 `sensitive`/绑定字段宣称为通用 JSON Schema 或 MCP 核心标准。

建议首批实现 MCPB 配置描述适配，保留原生插件外层；Registry 格式通过独立适配器归一化。不强迫所有插件重打包为 MCPB，不宣称任意 MCPB 都可直接运行。原生插件关联附属描述文件的规则若需要宿主扩展，必须使用明确的 newbot 命名空间及版本，文档标明其不是 Codex/MCP 原生字段。没有声明的包展示“尚未提供配置说明”，由作者或明确的管理员配置补充，不从 README 自动执行或推断秘密。

## CloudWalker 的具体映射

|用户填写|配置字段|MCP 子进程接收|存储|
|---|---|---|---|
|牧云平台地址|base_url，必填文本|CLOUDWALKER_BASE_URL|SQLite 普通设置；校验 URL 与接收方变更|
|API Token|api_token，必填敏感文本|CLOUDWALKER_API_TOKEN|复用加密凭证库；只在可信注入边界解密|

这里的地址是牧云业务 API 根地址，并非 stdio MCP 的网络地址。程序位置、启动参数、变量名由包声明；可选组织 ID、profile、证书等只有声明后才出现在高级配置。自签名信任和多 profile 不混入首批基本两项配置，也不自动放宽 TLS。

## 同类风险范围

|关联入口|共同机制与状态|纳入/排除|
|---|---|---|
|导入预览、已安装详情、未运行插件|只依赖原生发现会漏掉未识别的清单能力；已复现|纳入：展示包声明与实际支持的差异，禁止无声漏掉 MCP|
|HTTP API Key、HTTP OAuth、stdio env、无认证 MCP|统一配置与认证入口；后两类已有部分代码，插件范围缺失|纳入必要适配与能力检测，未支持类型明确说明|
|多个连接器、不同插件同名连接器、独立连接器同名|现有全局 server 名称及凭证目标；待验证碰撞路径|纳入稳定复合身份和归属校验，不能简单改成独立全局 MCP 以绕过|
|插件包替换与运行参数热更新|有代码证据：导入复用 privateConfiguration，而该方法在私密热更新模式下绕过空闲检查|纳入独立资源变更互斥边界；只有参数/凭证保存可并行，包安装替换仍等待空闲，完成后撤销旧 App 视图|
|技能目录和插件详情启停|共用技能设置与资产标识；有代码证据|纳入统一状态及真实下一轮执行验证|
|保存、重新编辑、升级、卸载、重装、重启|配置修订与包摘要/接收方绑定；待验证|纳入保留非敏感配置、秘密失效及操作幂等|
|运行中改 Key、切换会话、临时授权、断线|现有任务快照及私密授权；有代码证据|纳入下一轮注入，不重启共享运行时或重放业务工具|
|MCP Apps iframe|复用工具路由和身份；待验证|纳入应用调用归属，iframe 不获得 Key|
|完整插件商店、升级 Codex、真实牧云业务联调|非当前必要范围|排除；真实平台测试需用户配置授权，本机模拟不能代替|

## 分阶段实施与验收

### S0 调查和版本约束 — 已完成

- 保存安装基线、原生覆盖探针和标准来源。
- 证实普通 MCP 参数注入能力不能直接套在原生插件策略字段上。

### S1 包能力与配置描述 — 已完成

- 从受控包资源读取连接器归属、静态启动定义和用户字段描述，明确格式/版本、预算、引用限制和完整性。
- 先支持文本、数字、开关、必填、默认值、敏感字段及受控模板绑定；未支持的文件/目录能力解释服务端路径边界，不用浏览器本机文件选择器冒充服务器目录。
- 为 CloudWalker 补充明确的两字段描述；原始 ZIP 和源码保留，任何派生/迁移记录差异与摘要。
- 验证不同字段组合、无配置连接器、多个 MCP、不支持格式、缺少描述与恶意模板。

### S2 SQLite 配置、凭证与运行适配 — 已完成

- 以插件身份 + server 身份建立复合目标；配置值、Schema/包摘要和修订号持久化。普通字段与秘密分流。
- 在隔离环境确认可行的线程参数适配方式后才实施；原生策略只用于其确实支持的启停/工具策略。若必须由 Bridge 管理插件 MCP，明确记录其来源，解决命名冲突、原生重复加载和技能工具引用，不伪称仍是未改变的原生路径。
- 不落盘明文秘密、不写个人配置；全局设置下轮生效；当前运行保留原快照；同对象并发保护、未知保存结果可核对。
- 验证合成 HTTP/stdio 接收方取得对应值，其他插件/线程不得取得；升级接收方或二进制后授权重新核对；插件停用/卸载后不再注入。

### S3 插件统一管理界面 — 已实现，真实浏览器验收受阻

- 插件详情集中显示连接器和技能。连接器显示待配置/已配置/诊断失败及“配置”；字段由声明生成，默认隐藏启动命令、参数和变量名。
- 凭证显示“已保存”并支持替换/清除，不回显明文；无配置连接器直接启用，OAuth 显示账号连接。
- 技能支持同页查看说明与逐项启停，复用现有资产 ID、设置和反馈组件。
- 保留 ChatGPT 风格现有视觉体系，桌面/手机、深浅主题、键盘及空/错误状态验证，不增加冗余说明区。

### S4 实际链路与恢复回归 — 自动与原生验证通过，测试实例已更新

- 覆盖 CloudWalker 从当前已安装状态补齐配置、下一轮连接、技能及 MCP App 资源归属；不要求用户重复手工添加独立 MCP。
- 验证重启恢复、技能单独关闭、插件整体关闭、删除秘密、部分配置、迟到响应、MCP 无响应与包升级。
- 类型检查、构建及相关自动测试；真实浏览器验证受影响页面。浏览器工具不可用则记录具体阻塞，不将 API 验证写成 UI 验收。
- 仅在空闲维护窗口更新测试实例，保留既有会话、附件、Provider 与个人 Codex 隔离；不做正式上线验收。
