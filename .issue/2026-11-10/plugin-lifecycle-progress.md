- 当前测试服务、磁盘和公网首页仍对应 `index-BjJxw1dN.js`。初次只读请求已带插件归属；无法据此复现用户截图的全部时序。前端仍依赖运行状态生成独立行并等插件目录排除，已改为独立配置拥有目录成员，运行发现仅补充状态。对应 `baseline.json` 与目录回归测试；没有按 `plugin_` 前缀隐藏合法独立连接器。

- 原生 0.165.0 本地市场探针发现 `plugin/read` 的文件路径来自市场源，而实际运行技能来自安装缓存。原代码按源路径读取启停值，使插件详情把已禁用技能显示成启用；升级预览也会继承错误状态。已纳入 PL-02 共同机制，改为安装态技能作为详情、配置与升级选择的权威来源。证据 `native-upgrade-skill-baseline.json`（第一次失败时已证实；后续探针重跑会刷新该文件）。
- 原生本地市场来源文件变化后 `localVersion` 与 source 说明直接改变，单独调用 install 不能作为升级证据。导入包走受控升级事务；原生市场只在提供不同的已装/目标版本时开放升级，不能假造 `plugin/update` 原生 RPC。已核对 [官方 OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server) 与固定生成类型。
- 当前真实浏览器验证仍受 Work 设置限制。测试中的 mock/native/API 结果只证明对应边界，不声称已通过手机视觉验收或真实远程市场升级。
