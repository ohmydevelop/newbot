# NB-SYS-01 · 保留旧版体验的体系化重构

2026-11-15。当前执行计划，优先于本目录历史换框架/换视觉方案。

## 用户目标与约束
用户明确：“在旧版方案上，保持原有的所有的交互和界面，让它更体系化。而不是东凑西凑的。”本轮要求基于原旧分支创建新分支开发。

触发：上一实验页使用默认聊天组件，原侧栏、插件、技能、专家、设置等缺失，用户拒绝该结果。预期：仍是熟悉的完整newbot，内部组件、样式、状态和接口更一致且可维护。不变量：技术重构不能删功能、改变已确认的交互或默认更换视觉风格；每个操作只有一个有效执行路径；配置和历史保持兼容。

## 已知事实与根因
- 基于旧分支 main 的40754bf创建 codex/newbot-systematize；产品代码最后提交是d9f9d56。两者差异仅5个issue规划/调查文件。
- 原产品包含web/App.tsx、Sidebar、Settings、ExtensionsSettings、ToolsSettings、SkillsSettings、ExpertsSettings、MarketplaceSettings、聊天步骤、附件及工作台；基础使用Radix、Lucide/参考图标、Newbot CSS/tokens、Zustand、官方AG-UI/A2UI/MCP Apps。
- 此分支不继承codex/newbot-v1的CopilotKit实验工程及服务端适配改动。旧实验分支保留供调查参考，不能整体合并替换产品。
- 已确认的交付偏差是未完成领域功能接入就交付了简化shell，并非新框架必然要求删除原功能。具体组件重复、样式分叉、状态归属问题需要在本分支按源码逐项建立证据，不能凭视觉相似判定同根因。

## 同类风险与范围
| 范围 | 当前状态 | 纳入原因/后续检查 |
|---|---|---|
| 完整shell、导航、插件、技能、专家、商店、设置 | 有源码及此前浏览器证据 | 曾被实验shell遗漏；建立原行为清单，所有替换需保留真实入口和业务接线 |
| 按钮、菜单、弹层、表单、图标、状态反馈 | 待验证 | 跨业务共享交互；先定位重复与差异原因，再确定唯一公共实现，不能泛化掉业务差别 |
| 聊天发送/取消/切换/重连、思考与工具步骤 | 有现有机制证据，重构待验 | 权威状态和异步边界决定行为；覆盖重复发送、迟到事件、取消与恢复 |
| 插件/Provider配置、凭证、OAuth/CA | 有现有机制证据，重构待验 | 同保存/校验/持久化约束；不能只统一表单外观而留下生效差异 |
| 附件、A2UI、MCP Apps、文件工作台 | 有现有机制证据，重构待验 | 同消息/授权/资源生命周期；保留现有协议和历史读取，升级需独立理由和证据 |
| 生产数据、服务和实验预览 | 本轮不修改 | 新worktree避免切分支删除运行服务所依赖的源码，也保留当前未提交文件 |

## 修复范围与选型原则
保留旧版产品外观、布局、字体、配色、图标语义、所有已有功能与交互。体系化目标为：统一设计变量、共享控件、业务组件边界、事件/状态所有者、配置及错误处理。已有成熟库继续使用。

CopilotKit、Apps SDK UI等只在能够保留产品契约且确有维护收益时作为内部替换候选；不默认安装全套，不用默认聊天模板替代现有界面，不引入第二Agent循环。不得为了使用某个库先改变用户体验。A2UI等协议升级不能混在基础组件整理提交中。

排除本轮：重新设计产品、删除现有能力、改为实验页、全面升级依赖、目录大搬家、迁移生产数据、重建线上dist。真正行为变化需单独说明，不能藏在“重构”名义下。

## 实施顺序
1. 已完成：从旧main创建独立分支/worktree，记录当前约束，核对产品源码与旧基线相同。
2. 建立旧版基线：阅读PRODUCT/DESIGN及历史issue；盘点共享组件、样式和状态路径；在隔离运行环境截取桌面/手机、浅深色、深层表单和执行过程，不把老截图直接当当前证据。
3. 在本目录形成首批有代码证据的同类问题及计划：优先公共组件/图标尺寸/间距/状态反馈/表单骨架，先修共同实现，再迁移消费入口。
4. 按实际证据整理插件、技能、专家、商店、设置的领域组件与配置读写；保持API和持久化兼容，不复制安装器或权限机制。
5. 整理聊天/事件/状态边界；若采用框架局部替换，先验证即时发送、步骤折叠、滚动、取消、切换、重连、附件和审批，再删除被替代实现。每次只迁移一条完整路径。
6. 分阶段真实浏览器和针对性行为验证、更新记录。全产品等价验收后再部署，保留回滚路径和新增用户数据。

## 验收
原页面布局/主题/图标及操作顺序保持；所有原入口和已配置数据可用；桌面/手机与浅深色检查通过；相同控件具有共享实现且无业务行为丢失；一操作一次执行、过期请求不串会话、保存配置重启恢复。代码或依赖缩减需列真实删除与职责转移，不以新增文档或导入库作为完成证据。

测试覆盖原复现路径及共享入口，真实服务与模拟替身结果分开记录。分支创建阶段仅做Git祖先/差异/工作区检查，不宣称运行时功能已经重新验收。记录见newbot-systematize-progress.md。
