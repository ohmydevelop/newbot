# NB-V1-PARITY · 纠正简化预览替代完整产品

2026-11-15。原始反馈：“太烂了，一点都没有原来的那种效果好。比如说插件什么的都没了。”

## 用户目标与触发
用户通过刚交付的在线地址登录，预期在原能力完整保留的前提下体验新架构与设计。实际只有 CopilotChat 文本聊天、新建和主题切换，没有插件中心、技能、专家、商店、设置、历史导航或附件。破坏约定：技术迁移不能以删除已有能力为代价；实验验证不等于可替代产品的交付。

## 调查与因果
- 已复现：labs/v1-integration/web/App.tsx 仅挂载登录/header/CopilotChat，在线启动器明确限制业务 API。缺失是产品接入范围的结果，不是图标 CSS 或插件数据丢失。
- 有代码证据：原 web/App.tsx 仍挂载 Settings、RuntimeSelector、WorkbenchRail、附件和审批；ExtensionsSettings 包含连接器、技能、专家，ToolsSettings/MarketplaceSettings 是真实业务路径。
- 当前原进程 PID1291921、3100端口、原 dist 与 .data 保留；数据库活动20 completed /4 interrupted，无运行中活动。
- 已复现：原公网地址浏览器 ERR_CONNECTION_CLOSED；cloudflare-web.log 持续 Unauthorized: Tunnel not found。与功能缺失是两个独立问题。
- 已知：新实验页独立 .data/v1-online，不能通过简单改 webDirectory 指向原 UI 解决，否则 API 白名单及独立插件配置依然缺失。

## 实施与范围
1. 保存本计划；备份原 .env 与一致 SQLite 快照到忽略的私有目录。
2. 重建已失效的原 web 隧道，保留独立 Apps origin；仅更新 .env PUBLIC_ORIGIN，正常重启原服务加载，不重建/覆盖原 dist。
3. 公网验证原密码、原历史、插件/技能/专家/商店/模型设置入口及实际条目；确认新旧数据目录分离，记录截图证据。不安装新插件，不改变现有凭证或插件开关。
4. 更新主计划发布门槛与功能矩阵：先恢复完整产品可用性，再迁移内部实现；G1 lab 仅作研发验证，不能作为用户日常入口。新界面未接通完整功能前不得称为新版替代。
5. 交付完整功能入口和明确状态。保留实验预览与其数据供研发，不删除用户可能已创建的聊天。

不在本轮伪称完成全部 v1 框架迁移，不回退架构决策，不重新实现原插件系统，不绕过认证/Origin。依赖：原 dist/native/Provider 保持有效；Cloudflare quick tunnel 只保证本次实测可达，不承诺固定域名。
