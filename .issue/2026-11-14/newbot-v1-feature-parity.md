# NB-V1-PARITY · 用户可用版本的功能保留矩阵

2026-11-15。技术组件的更换不能降低原产品能力。新版本验收必须覆盖真实入口、领域数据、执行和恢复，不以控件存在或安装依赖代替接通。

| 功能 | 原实现/复用边界 | G1文本实验页 | 新版迁移的验收约定 |
|---|---|---|---|
| 聊天历史、搜索、新建、切换 | Sidebar、store、native历史 | 仅新建和当前会话恢复 | 原历史可读，切换不串会话，搜索/归档保持 |
| 连接器/插件 | ToolsSettings、PluginDetails、服务端原生插件管理 | 缺失 | 已有条目可读，安装/配置/启用/检查状态分别正确，实际执行使用所选插件 |
| 应用商店 | MarketplaceSettings、原市场导入 | 缺失 | 多商店，URL自动推断，刷新/重启恢复，失败可重试 |
| 技能 | SkillsSettings、原skill路径 | 缺失 | 完整名称、导入/启停/选择，实际发送携带有效选择 |
| 专家 | ExpertsSettings、专家配置/会话扩展 | 缺失 | 独立入口，提示词+插件+技能组合保存，重启恢复并实际生效 |
| 模型/设置 | ProviderSettings、Settings、revision机制 | 缺失 | 配置可读可改，当前轮冻结、下一轮切换，凭证不入普通事件 |
| 附件/文件工作台 | AttachmentPreview、WorkspaceFiles、WorkbenchRail | 缺失 | 真实上传发送，文本和图片分块，下载/预览/归属保持 |
| 思考/工具/审批 | ChatTurn、Approvals、session-runtime | 缺失 | 紧凑步骤、明确标题和状态、默认折叠、滚动衔接，取消及授权失败有恢复路径 |
| A2UI/MCP Apps | 原renderer与AppBridge、安全独立origin | 仅独立协议探针 | 原历史可读，新协议实际交互，受控工具调用，拒绝/过期不执行 |
| 手机/浅深色/图标 | 原设计约定、Apps SDK tokens迁移 | 只有简单聊天页 | 完整外壳及深层表单逐屏验收，原有功能不因屏宽消失 |

原完整产品恢复仅证明可继续使用既有实现；不把旧实现标为已完成CopilotKit迁移。以上实验页缺口有源码证据，实际端到端验证按模块补齐后才能改变状态。真实第三方OAuth等需要单列证据，不能继承历史“完成”描述。
