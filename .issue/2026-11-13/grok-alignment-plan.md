# Grok 风格对齐：分析与计划

日期：2026-11-13。来源：用户提供的 Grok 桌面端截图（`image-16/17/18/20/21`）与要求「深度分析 https://grok.com/，把相似功能的 UI/UX 深度复制，包括图标、配色、动画」。

## 一、证据与方法

- **grok.com 无法直接抓取**：用真实 Chromium 访问返回 403，页面内容是 Cloudflare 的 "Just a moment..." 验证页（证据：`.issue/2026-11-13/evidence-grok/landing.json` 与 `landing.png`）。无登录态、无挑战解题能力，因此**没有**做站点的 DOM/CSS 抓取。
- 采用用户提供的 5 张截图做像素级分析（ImageMagick 直方图 + 定点采样，3042×1588 为 2x 缩放）。
- 结论适用于「Grok 产品设计语言」，不等同于 grok.com 当前线上实现。

## 二、已量化的设计系统

| 角色 | 值 |
| --- | --- |
| 画布 | `#131211`（暖近黑，R>G>B） |
| 侧栏 | `#181716` |
| 抬升面（气泡 / 输入框 / 选中卡） | `#201F1D` |
| 悬浮 / 选中行 | `#2A2928` |
| 主文字 | `#FCFCFC`（我们因刺眼改为 `#E3E1DD`） |
| 次要文字 | `#9E9E9E` |
| 强调（语音球） | `#299FFF` |
| 描边 | 近 `#2D2C2A`，弱到几乎不可见 |

- 侧栏 299px、导航行 31–32px、图标 18px、输入框圆角 ~24px、气泡圆角 ~18px。
- 层级极平：抬升面只比画布亮 8 个色阶；分隔靠留白而不是描边。
- 图标语言：细线（~1.6–1.8px）、18px、圆角端点；操作行图标间距 8–10px。
- 动效（从截图无法量化，按产品惯例）：150–200ms ease-out、无弹跳、悬浮只改背景。

## 四、计划

### P1（本轮已完成）

1. 折叠态改为图标栏：56px，五个图标 + 底部头像；`aria-label`/`title` 齐全；≤760px 隐藏（抽屉模式）。
2. 侧栏底部新增「插件」入口；设置弹层里删除顶层「插件」标签。
3. 顶栏展开按钮在桌面隐藏（避免与图标栏重复）。

### P2 插件页按 image-21 重排（下一步）

- 顶部：分段标签（连接器 / 技能 / 专家）+ 搜索框 + 右侧主按钮（新建连接器）。
- 内容：两列网格；每行 = 24px 图标 + 名称（15px/600）+ 一行说明（13px muted）+ 右侧动作；**插件行不出现「添加」**，只有配置/启用/删除。
- 空态、加载态、错误态与现有能力保持一致；移动端降为单列。
- 复用 `ExtensionsSettings`/`ToolsSettings`，只改布局与行样式，不新增数据接口。

### P3 深度聊天气泡与动效

- 气泡：`#201F1D`、18px 圆角、最大宽度 85%（已接近）。
- 消息操作行补「更多」菜单（复制、查看原文）；点赞/重生成需新增持久化与接口，单独评估。
- 动效 token：`--motion-fast: 150ms`、`--motion-base: 200ms`、`--ease-out: cubic-bezier(.22,.61,.36,1)`，只用于悬浮/展开，不用弹跳；`prefers-reduced-motion` 关闭。

### P4 验收

- 桌面 1521×794 与移动 390×844 截图；浅/深两套。
- 断言：折叠栏 56px、图标 5 个、设置无「插件」顶层标签、插件页两列；控制台 0 错误。
- 回归：`npm test`、`npm run build`。

## 五、边界

- 不复制 Grok 的应用商店、语音、Bot 构建器、项目分组。
- 不引入第三方 UI 库；继续用现有 CSS token 与 lucide 图标。
- 不做对 grok.com 的抓取/登录，避免违反其访问控制。

## 推荐引导改为模型动态生成（已完成）

**问题**：之前的推荐是按正文正则从固定文案里挑，属于“固定套路”。

**协议**：模型在回答末尾追加一个语言标记为 `suggestions` 的代码块（JSON 字符串数组，2–3 条、每条 ≤64 字符）。宿主在渲染前剥离该块，并把它作为推荐按钮；没有该块或格式错误时回退到本地启发式。

- `shared/suggestions.ts`：`extractSuggestions()` 解析 + 校验 + 去除代码块。
- `web/components/chat/Message.tsx`：正文按剥离后的文本渲染，复制也复制剥离后的内容。
- `web/components/chat/Turn.tsx`：最后一条回复动态建议优先，缺失时回退启发式。
- `server/presentation.ts`：developerInstructions 增加“以 suggestions 块结尾给出 2–3 条具体下一步”的要求。

**验证**：`tests/suggestions.test.ts` 3 项（正常、无块、非法/超长/超量）；用模拟模型输出验证：正文只显示“这是动态答案。”，脚本块不出现，按钮为模型给出的两条（截图 `followups-dynamic.png`）。真实模型是否每次都遵守提示词，需要后续用实际对话观察；不遵守时仍有启发式兜底。

`npm test` 512 项（511 通过 / 1 跳过 / 0 失败），构建通过，服务已重启。
