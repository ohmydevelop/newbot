# UI-20261113-R2：文字清理、字重与导航对齐

## 反馈和预期

用户截图要求删除首页三个建议按钮及“newbot可能会犯错”提示；反馈字体尖锐、笔画细，并要求继续1:1对齐相似功能、图标和折叠。已完整查看附件，原图保存在evidence-grok-ui-refine/user-feedback.png。

## 证据、因果与不变量

- App仍显式渲染ChatStarters与全局composer-note；不是缓存问题，需移除渲染与废弃样式。
- 真实浏览器CSS.getPlatformFontsForNode：中文实际NotoSansCJKsc-Regular，拉丁NotoSans-Regular；正文400。当前无自托管字体，不能声称使用了不存在的Inter。改用明确的Noto/中文回退和真实Medium字重，避免用描边/阴影伪加粗。
- Grok现场：折叠栏总宽57px（内容56+边线），展开256px；顶部56px，折叠按钮32px/图形18px；主要导航36px/图形24px/圆角12px；按钮反馈100ms，侧栏组过渡300ms cubic-bezier(.23,1,.32,1)。newbot当前为64px、18px圆形按钮，且展开/收起卸载不同布局，缺少连续几何过渡。
- 约定：移除引导文案不得影响正常输入/模型/审批；折叠导航不遗留可聚焦隐藏元素；桌面收起偏好不被手机临时抽屉状态覆盖；键盘与触摸入口仍可操作。
