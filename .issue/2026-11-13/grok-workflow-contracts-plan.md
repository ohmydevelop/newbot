# GCF-9 工作流程与插件操作约定

日期：2026-11-14。状态：已实施、已部署并验证；触控与非GitHub深层链接限制见进度记录。承接 GCF-8，保留历史记录。

## 用户目标、触发和实际行为
GCF9-1：展开聊天工作流程，应紧凑显示每步任务和真实状态，思考内容默认折叠。现有 Message 初始化 reasoning 为展开，完成状态被 sr-only 隐藏；summary 在 shell 样式被覆盖至 40/44px。
GCF9-2：在流程和工具详情滚动到边缘，应继续滚动聊天查看其他消息。两个层级的 overscroll-behavior-y:contain 阻止滚动链。
GCF9-3：粘贴商店链接应推断分支、目录。现有表单仍有手动 ref/sparse，native add 直接收到网页目录 URL；已有 GitHub 导入解析器能够解析含斜杠的分支，可复用。
GCF9-4：专家是提示词、插件、技能和连接器的组合，应独立入口。当前技能过滤器混入专家，保存 schema/content/捕获快照均没有提示词。
GCF9-5：连接器、商店、导入应图标语义不同，连接器列表即浏览目录，不再有重复浏览插件模态框；显而易见的表单字段用简洁输入提示和无障碍名称。

## 不变量与证据
- 显示状态来自执行事实；不得将中断/失败显示成完成。折叠状态由用户控制，流式追加不强制打开。
- 内层只消费可滚动距离，边缘可以继续看聊天；保留有界窗口和最新步骤定位。
- 同一链接确定版本和目录，快照不被源后续修改污染；失败不改变注册表，更新沿原链接重新解析。
- 专家保存后重启可恢复，每次发送捕获独立提示词快照，编辑专家不能改变已预留请求；生成的专家上下文不泄露到用户消息显示。
- 原生 Codex 管理插件解析/安装，URL 转换只负责来源定位。
源码证据：Message.tsx、ProcessGroup.tsx、styles.css/shell.css、ExtensionsSettings.tsx、shared/experts.ts、server/experts.ts、bridge.ts、marketplaces.ts、github-imports.ts、ToolsSettings.tsx。
参考：真实 Grok 既有聊天 3d62c744-81db-4b51-b535-ac782497fa96，只读展开；初始 Thought for 51s 折叠，展开后 Searched the web 为完成式标题，工具行实测 24px/15px 字号，展开后逐项查询标题可见。仅作 UI 参考，不采信回答新闻内容。

## 范围与实施顺序
1. 共享流程折叠、状态、密度、滚动链；不改变原执行顺序或 A2UI 待办。
2. 专家第三分类，提示词端到端保存/快照/注入/装饰；content JSON 添加可选字段，旧记录默认为空，无 schema 迁移。
3. 共享 GitHub 定位和归档能力用于商店 URL；去掉表单手填分支目录，后台保留旧字段兼容已有来源。
4. 删重复浏览入口；语义图标和精简连接器表单；保留 aria-label 和必要授权控制。
5. 针对测试、隔离真实浏览器检查、独立 Impeccable finish review；修正后备份部署原3100服务并验证原 Cloudflare 地址和真实模型。
不扩大到任意第三方平台转换器、凭据修改或重写整个运行引擎。

## 验收与证据
- 每步标题可辨认，完成/运行/失败/未完成准确；默认思考关闭，用户展开不因增量丢失。
- 长流程内部能滚动，顶端继续向上能移动外聊天；工具详情同样；桌面鼠标及移动触控实测。
- 专家独立三分类可键盘切换，提示词可保存重读，捕获旧版本不受后续编辑影响，原生模型输入包含提示词，聊天正文不显示注入上下文。
- URL含分支/子目录自动解析，错误/不支持地址不污染现有商店，原生 Codex读取测试（模拟网络与真实网络证据分开）。
- 手机320/390和桌面暗浅主题无溢出；添加连接器和商店无冗余标题，所有输入有可访问名称。
- 构建产物、运行服务、原访问入口一致；备份保留历史会话和配置。
