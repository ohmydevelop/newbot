# UI-20261113：Grok 参考驱动的 newbot 界面重构

## 用户目标与现状

用户要求拆解 Grok UI、UX、动画、配色、图标和组件，并彻底重构 newbot；已确认日常聊天优先、工具和设置按需展开、高度接近 Grok。触发路径：打开新聊天、历史会话、输入工具、设置与工作区，在桌面及手机之间切换。

这是一项产品重构，不把审美差异冒充已复现缺陷。现状代码：web/App.tsx 同时拥有会话状态与页面组成；web/styles.css 6503 行，布局、功能样式和多轮补丁混合；共享主题已覆盖大量弹窗。原首屏有图标、介绍、三个建议按钮，输入框在底部。目标为 Grok 式低干扰聊天画布、紧凑导航、突出的输入区与按需工作区。

## 不变量与根因判断

- 任何视觉改造保持发送、停止、回执、会话草稿、模型切换、审批、私密字段的状态所有者和 API。
- 菜单/弹窗打开后焦点可达，关闭后恢复；窄屏无页面横向滚动，输入与关闭按钮始终可操作。
- 浅深色共享语义 token，错误/警告不依赖纯颜色表达；减少动态效果偏好有效。
- 有代码证据：共享组件与样式是全局一致性的正确修改点；右侧栏 overlay 规则后出现 .rail { position: relative }，可能覆盖窄屏 fixed，需浏览器验证。
- 已实测：Grok 可见首页的色值、几何、字体回退、图标和按钮过渡，详见 grok-ui-analysis.md。菜单和设置精确动画未采集，不作全站复刻结论。

## 实施顺序与边界

1. 观察 Grok 可见页面，记录实测 token/布局/交互与不可访问部分；Craft Anything 授权关卡未解除前不绕过。
2. 记录产品事实、方向契约，运行隔离 newbot 夹具截取基线。核对源码、候选构建、访问入口。
3. 重构共享设计 token、导航、首屏与 composer 排布；覆盖消息、菜单、设置、目录、工作区和登录。保持现有业务与组件边界。
4. 修正同机制响应式与焦点问题，加入用途明确的短动效与减少动态效果处理。
5. 类型检查、构建、适配现有行为检查；真实浏览器桌面/手机、浅深色验证；独立设计审查；保存最终设计文档。

不做：后端重写、品牌克隆、Grok 付费能力模拟、无关依赖升级、生产发布或重启既有服务。无需数据迁移；现有 localStorage 偏好继续有效。使用独立候选构建与测试端口，用户原有未跟踪 issue 文件不改动。

## 验收

- 首屏聊天输入成为视觉中心；侧栏与工具保持低干扰且可发现。
- 桌面 1440、平板 900、手机 390 与当前用户窄屏 320 无主要控件遮挡/横向溢出。
- 新建/切换/搜索会话、编辑建议、附件菜单、模型面板、插件/技能、设置主题、工作区打开关闭可用。
- 发送/停止及失败提示不被视觉改造破坏；模拟上游结果明确标注边界。
- 类型与构建通过；截图/检查结果落在 evidence-grok-ui；设计审查结论与限制写入进度。
