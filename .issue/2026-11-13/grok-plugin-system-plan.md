# GCF-7 · 插件系统与设置对齐

## 用户目标与触发
用户从侧栏进入插件、选择连接器/技能/专家、查看详情并管理能力，再返回聊天；设置也应沿用同一视觉语言。现状是四个独立后台页，各自搜索、工具栏和多层详情弹窗。预期是 Grok 式紧凑插件中心：同一面板内浏览、搜索、深入、返回，桌面双列、手机单列；少说明文案，必要权限/错误/恢复提示保留。

## 不变量与证据
- 功能身份图标在目录、选择、执行、设置之间一致；不由可编辑名称猜测。
- 搜索/返回不能丢失目录上下文；迟到详情不得覆盖新选择；离开页面不改变配置。
- 启用、安装、连接成功与会话选用是不同状态，不可用一个“已添加”掩盖连接失败。
- 原有 revision、私密字段保护、保存结果未知时恢复、技能版本校验必须保留。
- 观察证据：evidence-grok-plugin-system/grok-connectors-desktop.png、grok-skill-detail.png、grok-settings.png、settings-paths.json。Grok 插件标题隐藏、两主分类、顶部搜索/新建、同面板详情；设置采用左侧分类、小图标、单项行。新技能菜单为手写/上传/通过对话创建；不能虚构 newbot 尚无的创建服务。
- 源码证据：ExtensionsSettings 四标签分别挂载；ToolsSettings 详情/市场用嵌套 Modal；SkillsSettings 详情取代工具栏；CatalogToolbar 搜索/操作重复；Settings 通用含额外技术说明。共同原因是没有共享目录容器和导航层级，而非单一图标错误。

## 同类风险与检查
|范围|状态|共同机制与处置|
|---|---|---|
|插件、连接器、技能、专家目录|有代码证据|独立工具栏/详情层级，统一容器与回退|
|插件内技能/连接器、专家成员|有代码证据|复用详情；容器需支持逐级返回，不能一次关闭全部|
|搜索后查看返回、键盘焦点|有代码证据|卸载列表丢失焦点；保留挂载、恢复触发项|
|目录请求迟到/切换分类|有代码证据|ToolsSettings 请求代次与卸载失效边界；浏览器切换分类可用，未注入网络延迟模拟|
|创建/导入/启停/升级/卸载|有代码证据|相关管理测试通过；隔离浏览器验证创建、编辑冲突、导入取消；未在生产执行破坏性操作|
|私密配置、授权、连接测试|有代码证据|保留既有 ConfigurationFeedback/ConnectorEditor 保护；真实账号仅查看|
|当前会话选用与历史消息|有代码证据|隔离浏览器验证技能、专家、插件选用，无文本注入；生产重启保留全部既有聊天与run|
|桌面/手机、浅色/深色|已复现并修复|真实浏览器发现并修正320px设置标题重叠；1440/390/320截图验证，浅深色无横向溢出|
|插件技能显示元数据|有代码证据|插件详情丢失 interface.displayName/shortDescription，补充兼容字段；原执行name/id不变，无数据库迁移|

## 范围与实施顺序
1. 完成参照/现有实现核对，建立共享目录框架、同面板详情和回退。
2. 连接器下容纳插件包与独立连接；技能保留专家组合管理入口，不冒充 Grok 的账号机器人能力。统一搜索、新建、状态/更多操作。
3. 同步设置图标、条目密度、外观操作和短文案；保留错误、权限与破坏性操作影响说明。
4. 隔离实例验证浏览/返回/搜索/编辑/取消/失败、插件子能力、技能和专家；执行相关测试与类型检查。独立视觉复核后发布。
5. 备份现有静态产物，发布到用户正在使用的 3100 实例与 Cloudflare 入口，核对公网产物和配置未变。

不处理：虚构第三方市场、修改 Grok 账号、替换品牌、变更模型/凭证/权限、无关后端重构。既有配置和引用不迁移。

## 验收
- 插件从同一入口发现，主分类/搜索/新建固定；详情在面板内逐级返回。
- 各类真实可用功能仍可到达；空态/失败态准确，无固定推荐内容。
- 手机 390/320、桌面 1440 可用，按钮可触达，长名称不挤出操作；浅深色同一套中性色。
- 图标按采集路径或同语义系统统一，设置无重复介绍；读屏名称和键盘导航保留。
- 验证记录区分真实浏览器、隔离数据与真实服务；公网 HTML/资源匹配发布产物、现有进程及配置安全。

状态：本轮界面重构、独立收尾复核、实际实例部署及真实模型验证完成。生产验收发现的 GitHub 详情读取失败与 hids 连接失败保留为未解决运行时状态；未改变凭证或权限。证据、验证边界见 grok-plugin-system-progress.md。

补充范围：子技能详情实测发现目录只展示原始执行name，服务器未传已有displayName。仅补充显示元数据字段和回归断言，保持执行身份/配置不变。此变更需要实际实例空闲维护锁、完整构建备份和服务重启；不强制中止任何用户任务。

返回焦点补充（发布前复现）：插件子技能阅读会临时卸载触发按钮，layout effect 才捕获 activeElement 时已变为外层对话框。统一 CatalogDetail 在渲染切换前记录触发项，卸载后按原项/父详情标题回退；不逐个入口复制修复。复测子技能 Escape 与目录搜索返回。
